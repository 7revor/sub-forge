## 需要修改的画板

1. **全局侧栏与模板画板**：只保留「规则」分组中的一个「模板」入口，且仅管理员可见。移除「管理员」分组中的「模板管理」入口及重复的管理列表画板。管理员的模板页统一承载列表、查看、新建、编辑新版本和发布入口；编辑器、发布前校验仍是子页。标题和面包屑统一写「模板」。普通用户不显示独立模板页或菜单；新建配置订阅向导仍可选择已发布模板。
2. **所有页面的空状态**：对照截图中模板页的空白区，统一为浅灰页面底色上的白色虚线框。列表无数据、搜索无结果、详情卡片尚无成员或记录等状态使用同一视觉语言；保留各处原本有用的说明和操作按钮。按各画板实际页面结构调整尺寸，避免在小屏造成横向滚动。
3. **随主分支最新结构同步**：规则包已并入规则集，画布更新时以当前 `main` 的路由和页面为准，不恢复旧 `/bundles` 页面或菜单。
4. **订阅源详情 `Source` / `SourceFetch` / `Pipeline`**：移除「拉取参数」入口和设置弹窗，改为详情页顶部直接展开的「基础设置」。其下方仍是「处理链｜总览」左右结构，不把处理链和总览拆成上下两块。快照历史放在基础设置底部，可页内展开；统一使用页头「保存修改」「保存并拉取 / 立即拉取」和「删除」操作。
5. **订阅源列表与新建 `Lists` / `Dialogs`**：一个订阅源仅一个 URL。移除地址列表、序号、「添加地址」和逐条删除；列表地址列显示单个地址。新建仍用名称与单 URL 对话框，提示多个来源应使用组合。

## 订阅源基础设置版式

参考规则集 `RuleSets` 的来源设置，不引入第三方 Form 库。复用现有 `Field` / `Input`，数值用 `DraftInput`：

- 卡片标题「基础设置」，右侧轻量说明「修改后自动预览 · 保存后生效」。标题与字段区以浅色分隔线分开，内边距 16 px，字段间距 12 px。
- 第一行：订阅地址占满宽度，输入框 38 px 高，下面提示「每个订阅源使用一个 URL，多个来源请通过『组合』合并。」
- 第二行：名称、User-Agent、快照有效期（小时）、超时（秒）等列排列；标签在控件上方、控件顶边和高度对齐。窄屏按可用宽度自动换行，避免溢出。
- 选填拉取选项默认占位符分别为 `clash.meta`、`24`、`10`；公共说明位于字段下方，标明留空默认与最短 5 分钟。快照历史位于最底部的折叠行。
- 整体层级为「页头 → 基础设置 → 处理链｜总览」。宽屏处理链在左、总览或选中步骤的编辑预览在右；窄屏自然换行。页头保持固定，内容区滚动。
- 修改单 URL 或 User-Agent 后自动预览草稿，失败时显示错误并清除旧地址结果；保存统一提交基础设置与处理链。快照历史只显示正式拉取记录。
- 数据对应单个 `url: string`，不再绘制多 URL 编辑交互。多个来源合并交给组合页。

订阅源实现位于 `packages/web/src/pages/Sources.tsx` 的 `BasicSettings`，下方复用 `PipelineEditor`；字段样式参考 `Rulesets.tsx` 的来源设置。
