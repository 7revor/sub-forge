# 11 · 前端功能与设计稿覆盖盘点

设计稿：Claude Design 画布 [Sub-Forge 前端页面设计](https://claude.ai/artifact/XceERK5VmwqhEPai8xevKd)（原 21 张画板）。
本文逐页对照 `packages/web` 的现有功能，分三类：

- **有设计**：画板覆盖，前端按画板实现；列出与画板的出入。
- **无设计**：前端已有、画板没画的功能。本轮先在画布上补画（见文末「补充画板」），再按补充画板重写。
- **有设计、无实现**：画板画了，但服务端还没有对应能力；本轮不做，记录在此。

## 有设计

| 画板 | 路由 | 与画板的出入（重写前） |
|---|---|---|
| 总览 `Main` | `/` | 基本一致 |
| 订阅源 · 处理链编辑器 `Source` | `/sources/:id` | 步骤行多了启用开关与删除按钮；「添加处理器」做成了下拉框 + 按钮；预览缺「命中」列和「diff / 节点列表」切换；自动去重兜底不在步骤列表里；头部缺「拉取参数」入口（参数直接铺在页面里） |
| 组合 `Collection` | `/collections/:id` | 成员表缺「类型 / 节点数 / 拉取失败时」列；组合自身处理链没有用只读摘要 + 「在处理链编辑器中打开」，而是整套编辑器；缺合并后节点卡片 |
| 本地节点 `LocalNodes` | `/locals`、`/locals/:id` | 画板是「分组标签 + 节点表 + 右侧编辑」一页完成；实现拆成了分组列表页和分组详情页，节点是左侧列表而非表格 |
| Profile · 新建向导 `ProfileNew` | `/profiles/new` | 基本一致 |
| Profile · 概览 / 基础设置 / 节点集 / 策略组 / 规则 / 代理链 / 预览 | `/profiles/:id/:tab` | 基本一致；代理链「添加链规则」的编辑表单画板没画（见无设计） |
| 规则集 `RuleSets` | `/rulesets/:id` | 画板是「解析结果 / 客户端改写 / 输出预览 / 下载地址」，来源只有「编辑来源」按钮；实现把来源编辑铺在页面上 |
| 规则包 `RuleBundle` | `/bundles/:id` | 基本一致 |
| 模板编辑器 / 发布前校验 | `/templates/:id` | 基本一致 |
| 基础设置预设 `Presets` | `/presets`、`/presets/:id` | 画板是「左侧预设列表 + 编辑区 + 引用方」一页完成；实现拆成列表页和详情页 |
| 用户 `Users` | `/users` | 缺「共享的订阅源与组合」（服务端无此能力） |
| 手机 · 订阅链接 `Mobile` | 各页窄屏 | 窄屏导航已折叠；未逐页核对 |

## 无设计（本轮补画）

| 功能 | 现状 | 补充画板 |
|---|---|---|
| 处理链：12 种处理器的参数表单、添加处理器的选择、启用 / 删除步骤 | 自行在步骤列表下方加了表单；正则改名的匹配框被挤没（已修） | `Pipeline` 处理链 · 编辑步骤；`PipelineForms` 处理器表单 |
| 订阅源：新建、来源与拉取参数（地址、UA、快照有效期、超时、本地内容）、快照历史、删除 | 全部平铺在详情页 | `SourceSettings` 订阅源 · 新建与拉取参数 |
| 列表页：订阅源、组合、配置订阅、规则集、规则包、模板 | 通用 `DocList` 表格 | `Lists` 列表页 |
| 登录、账户（改密码） | 自行实现 | `Login`、`Account` |
| 对话框：粘贴导入、分组 YAML、插入私有规则、添加节点集、链规则编辑、创建用户、重置密码、版本对比、删除确认 | 各页自行实现，样式不统一 | `Dialogs` 对话框与危险操作 |
| 普通用户浏览模板 | 模板详情的「查看」模式 | `TemplateBrowse` 模板浏览 |
| 表单 / YAML 双视图（本地节点、预设、模板） | `DualEditor` | 并入 `Dialogs` 的通用控件说明 |

## 有设计、无实现（本轮不做）

| 画板 | 缺什么 |
|---|---|

| 用户 · 共享 | 服务端没有共享模型 |
| 侧栏「规则仓库」「系统」入口 | 随上面两页一起做 |
