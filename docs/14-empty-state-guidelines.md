2026-10-29：按用户提供的「客户端改写」截图统一空白占位，并修复说明文字贴近虚线框的问题。红框是问题标注，不是产品样式。设计稿尚未同步，任务见 [画布待同步清单](13-design-canvas-sync.md)。

## 公共组件与尺寸

唯一空状态实现为 `packages/web/src/components/Empty.tsx` 的 `Empty`，由 `ui.tsx` 继续导出，已有调用不需改导入。下拉组件直接引用独立文件，避免与 `ui.tsx` 循环依赖。

| 项目 | 默认值 |
| --- | --- |
| 外框 | 白底，1 px `#d5d9e0` 虚线，10 px 圆角 |
| 排列 | 标题、说明、可选操作居中，宽度跟随容器，无固定最小高度 |
| 内边距 | 四周 28 px |
| 标题 | 14 px、半粗、深色，允许换行 |
| 说明 | 12.5 px、灰色、1.625 行高，最大宽度 420 px |
| 标题与说明 | 8 px |
| 操作与上一段内容 | 16 px，多个操作自动换行 |
| 下拉候选空态 | `size="compact"`：12 px 内边距、12.5 px 标题，沿用相同边框、圆角和对齐 |

长名称和连续字符串允许断行；组件 `min-width: 0`、不参与纵向压缩。不要在页面重新拼装虚线占位框或直接覆盖组件的边框、字号、内边距。`className` 用于必要的外部布局。

## 外部间距

- 公共 `Card` 标题栏与正文间距统一为 16 px。
- 卡片级说明使用 `Card description`，由组件明确提供 16 px 下边距及舒适行高；不依赖浏览器默认段落 margin。Tailwind 重置会清除默认 margin，这正是截图中说明贴框的原因。
- 说明包含在业务表单内部时，父容器用 `gap-4`，段落设 `m-0`，不要再给空框叠加上边距。例如规则集来源设置。
- 空框后紧跟独立操作区时保留 16 px，例如配置订阅策略组下方「新增私有组」。
- 卡片正文默认左右与底部 16 px；表格容器 `bodyClass` 自定义时，空框外层仍需补左右和底部内边距。空框不放在仅为非空表格设置的宽度下限中；模板组为空时不再继承 760 px 最小宽度。

```tsx
<Card title="客户端改写" description="作用于整个规则集……" actions={addButton}>
  {items.length ? <ItemList items={items} /> : (
    <Empty title="没有客户端改写" description="添加后将统一应用于整个规则集。" />
  )}
</Card>
```

## 全站排查与归一范围

| 区域 | 处理结果 |
| --- | --- |
| 通用资源列表与搜索、模板/预设列表 | 沿用公共 `Empty`，统一获得换行、操作间距等改进 |
| 总览、订阅源快照、组合成员、本地节点、处理链节点对比 | 已使用公共 `Empty`，保留原有提示和操作 |
| 配置订阅：订阅链接、渲染记录、访问日志、节点集、策略组/成员、规则、代理链/依赖 | 已使用公共 `Empty`；策略组底部操作区补足 16 px 留白 |
| 规则集来源与客户端改写 | 同一公共空框；说明与内容间距统一 16 px；旧改写迁移提示下方也保留 16 px |
| 规则集输出预览 | 空结果由黑色代码框中的「（空）」改成 `Empty`；有内容时保留代码视图 |
| 模板详情与编辑器 | 补齐策略组骨架、组成员、规则、未发布版本和空版本记录；保留 MATCH 出口编辑与显示 |
| Surge 预设、配置订阅基础设置 | 两处手写占位统一使用有标题和说明的 `Empty`，继续说明功能在 M2 提供 |
| 下拉候选无结果 | `Select` / `Combobox` 共用紧凑 `Empty`；仍允许输入非候选值 |
| 规则仓库、系统白名单/仓库索引、用户共享、添加节点集对话框 | 已使用公共 `Empty`，保持现有业务能力 |

本规范针对替代内容区域的 blank。输入框 placeholder、表格单元格「—」、统计值、校验成功「没有问题」、差异结果「无变化」、行内提示以及带操作的虚线按钮都有独立语义，保留其原样。`PendingNotice` 是服务未接入提示，继续独立展示；加载和错误不是空结果，规则集加载提示已不再复用 `Empty`。
