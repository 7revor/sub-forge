# 设计稿再次视觉复核

本次在 `codex/design-v2`、基线 `1d90303` 上继续修正。参考为用户提供的 `Sub-Forge 前端页面设计.html`，使用其 21 个画板；浏览器操作、测量和截图全部通过 Codex 内置浏览器完成。没有安装依赖，没有调用独立 Playwright 或 Chromium。

## 本轮修正

- 订阅详情页签上移 8px，对齐原稿的 y=142；节点名称和说明拆为固定行高，操作列统一 64px。
- 修复小型分段按钮同时带有两组水平内边距的问题：“引用／展开”从 104px 收敛到 88px；预览诊断筛选改为整行等分、36px 高。
- 策略组列宽、字号、成员弱化色、模板“留空”与订阅“空组”状态对齐。编辑／删除使用原稿的 28px 图标按钮，删除仍经过原有业务确认。
- 规则、仓库路径使用等宽字体；规则出口列、拖动柄及操作列对齐。出口菜单补齐选中勾及“直连／拒绝”说明；添加规则按钮补下拉箭头。
- 代理链摘要改为前置与落地浅底标签，空状态的边框、字号及高度对齐；预览报告补齐分隔线、行内边距及底部查看入口。
- 仓库页添加入口移至页头，分区标题改为 15px，表格列比例及底部留白修正。表头 37px、数据行 36.5px；修正上一轮把 41px 数据行作为目标尺寸的结论。
- 订阅源、组合、规则集合基本表单顶部内边距从 20px 改为 16px；本地节点新增按钮改为 28px，复制操作改为无边框。
- 列表名称行高修正，行内复制链接移除多余图标；模板详情补齐面包屑名称。
- 系统／账户内边距改为 20px，分区标签改为 14px、500 字重；资源异常补计数标签及边框卡片。
- 策略组筛选条件移入默认收起的“高级设置”。这是按项目 AGENTS.md 的硬性规则执行，默认只展开名称、类型和成员；设计稿中的常驻筛选区不覆盖该规则。

## 测量与交互验证

[表格 DOM 测量](table-metrics.json) 包含参考与实现的坐标、宽高、字号、行高、字重、内边距及颜色。双方表头均为 37px、行高均为 36.5px、分区标题均为 15px/22px。列宽仍随可用内容宽度有约 0.4–1.5px 的差异，不将它报告为整图零差。

[退场汇总](motion-summary.json) 与 [逐帧原始结果](motion-results.json)：本轮 10 次关闭全部通过，其中 9 次正常动画、1 次无动画，共 240 个 closed 帧。覆盖策略组高级输入与重开、成员浮层 Escape 后关闭、代理链、手写规则、仓库、兼容插入规则、远程规则读取后的正文、前置规则填值关闭。标题、正文、输入、展开状态及布局宽高保持到实际卸载；无动画直接卸载并正常完成 Promise。

完整应用另验证直接删除策略组入口打开统一确认弹窗，点击取消后组仍存在、页面仍为已保存；没有执行持久删除或保存测试草稿。全部使用隔离测试库。

上轮的 24 个弹窗、75 次关闭及嵌套、保存失败重试、路由离开、StrictMode 和 Host 重挂证据保存在 [上轮报告](../design-v2-motion-review/README.md)，属于历史覆盖，本轮不重复计入 10 次结果。

## 验收边界

本轮是按全部画板重新检查、修复实际发现的视觉差异，并对修改涉及的组件与弹窗做回归。不是每种业务数据与每个交互状态的无限全排列，也未重新执行上轮所有业务流程。导航依用户要求保持原状，其宽度与设计稿不同；高级区按项目规则默认收起。保留真实业务校验、可访问性焦点环、错误信息及已有能力限制，不为静态外观伪造数据或成功状态，因此不宣称所有页面整图像素差为零。

临时前端、后端与参考 HTTP 服务验收结束后停止，依赖临时链接移除；工作树保留，提交后不自动合并。
