日期：2026-10-31。工作分支：`codex/design-v2`，起点：`2b22ca3`。

## 范围与依据

依据用户提供的 `Sub-Forge 前端页面设计.html` 中 21 个画板的 HTML/CSS、字体和布局参数调整全站内容区、公共控件和统一弹窗。左侧导航保持原有结构与交互，`layout.tsx`、`components/ui/sidebar.tsx` 无改动，并对侧栏字体及圆角做样式隔离，避免新主题影响原导航。

| 画板 | 落地范围 |
| --- | --- |
| 01–03 基础规范、组件、布局 | 字体、字号、行高、颜色、间距、边框、圆角、按钮、输入框、卡片 |
| 04–05 订阅节点与分流 | 四个详情页签、来源行、策略组和规则列表、模板入口 |
| 06–07 策略组、代理链、规则、模板关联 | 成员选择与预览、收起的高级设置、双栏代理链、规则出口、模板关联弹窗 |
| 08–09 客户端配置与预览 | 左侧客户端树、原文草稿、深色代码与行号、转换报告定位 |
| 10 订阅源处理链 | 基础表单、步骤列表、步骤编辑、替换表格 |
| 11 列表 | 表格列宽、紧凑备注、分页与更多菜单 |
| 12–14 规则集合、模板、本地节点 | 双栏规则工作区、模板编辑、本地节点列表与 YAML 工作区 |

| 20–21 总览与登录 | 统计卡、资源列表、日志与登录卡片 |

Inter 与 JetBrains Mono 拉丁字体随前端资源提供，附 OFL 授权；中文使用系统字体。保留业务已有的字段、数据与校验，因此数据数量和部分高级控件会影响实际高度；代理链来源类型选择等现有功能仍保留。

## 验收边界

- 内置浏览器拒绝打开原设计稿 `file://` 地址。本次直接读取设计源码参数实施，并对实际页面截图检查；没有对原稿与实现做同视口逐像素图像差分，不能认定像素级 1:1 已全部验收。
- 本次未对每一个弹窗逐一执行完整关闭入口、嵌套、路由离开与异步晚响应组合。相关自动化架构及生命周期测试通过，不等于所有浏览器组合均已实测。
- 未验证真实上游订阅拉取成功、节点连通性成功、密码修改、用户权限或共享资源写入。示例订阅使用无效测试域名，拉取失败提示为预期。
- 用户页部分后端共享统计处于等待状态，仅检查页面布局，不将其列为功能通过。
- 窄屏策略组截图记录于标题对齐细调前；最终标题采用左对齐。其余截图记录对应验收时的数据状态，不是固定生产样例。
