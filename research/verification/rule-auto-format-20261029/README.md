# 规则输入自动识别与输出格式验收

日期：2026-10-29。分支：`codex/rule-auto-format`。基线：`main@b6e0137`。

## 行为

- 规则集与自定义仓库不再让用户选择输入格式；保存可省略 format，缺省 auto。
- 文本与 YAML payload 根据实际内容解析，旧文本格式不强制决定解析器。来源摘要显示识别结果。
- 预览转换为规则文本；单个启用远程来源、无额外处理且客户端兼容时，下载配置引用原地址并设置实际 format/behavior。
- 多来源、覆写、IP 选项、拒绝行过滤或方言转换：一个 `.list`，`format: text`、`behavior: classical`。no-resolve/src 留在各自 IP 行内。
- YAML domain 的前导点保留仅匹配子域的语义，Surge DOMAIN-SET 前导点保留包含根域的语义。
- 旧二进制来源只保留原有能力；无法转换时明确报错，不静默遗漏。没有新增 MRS/SRS 解码器。
