# 订阅源单一状态列验收（2026-10-30）

移除订阅源的独立快照状态列，将统一“资源缓存”列改为“状态”。正常显示绿色“正常”，刷新中显示中性状态；失败与旧缓存合并为一份提示。上次刷新时间仍在操作列前，失败时间不替代成功时间。其他可刷新的文档列表也统一列名，不影响详情页与总览的状态组件。

前端继续复用资源状态接口，减少列表上的重复快照查询；服务端响应、模型、数据库与种子不变。全项目类型检查、最终前端构建及 325 项前端测试通过（2 项跳过），构建保留既有体积警告。

Codex 内置浏览器使用回环地址 18893 的虚构内存数据：

- 表头只出现一列“状态”，不再出现“资源缓存”。
- 两条正常来源分别显示一份“正常”。
- 点击刷新后关闭弹窗，列表只显示一份“刷新中”。
- 模拟失败后，一条显示“1 项失败 · 使用旧缓存”，另一条仍为“正常”，成功时间不变。
- 组合列表继续使用同一状态列。
