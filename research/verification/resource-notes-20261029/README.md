# 资源备注字段验收

日期：2026-10-29。分支：`codex/resource-notes`，基于 `630a60a`。

## 功能范围

订阅源、本地节点分组、组合、规则集均新增可选字符串字段 `note`。支持新建时填写、详情页修改和清空，随现有保存操作持久化。列表在名称后显示备注，保留换行、允许长文本折行，空值显示“—”。已有文档无需数据库迁移。
