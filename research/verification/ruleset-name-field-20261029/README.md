# 规则集名称表单验收

- 日期：2026-10-29。
- 环境：独立测试数据库，生产构建由本地测试服务托管，浏览器使用 Codex 内置浏览器。
- `pnpm --filter @sub-forge/web build` 通过，包含 TypeScript 检查；构建仍提示单个产物超过 500 kB。
- 新建规则集：基本信息第一项为名称，填写名称和本地规则后保存成功。
- 已有规则集：可直接在基本信息修改名称，保存后刷新仍显示新名称；顶部无重命名按钮。
- 空白名称：仅输入空格并保存，显示“请填写名称。”，未保存。
- 来源表单：本地来源和新增远程来源均无名称输入框，格式、缓存及本地内容字段正常保留。
