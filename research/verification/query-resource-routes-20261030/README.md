重点覆盖：

- `/api` 只认登录会话；资源入口只认用户 token；有效 Cookie 不能补足无效 token，token 不能换取管理权限。
- GET 动态路径和旧 `/sub`、`/p`、`/r`、`/rules`、`/nodes`、`/api/files` 均停止服务；重复/未知/冲突文件参数拒绝。
- 公共规则和仓库产物跨用户共享，订阅专属规则按用户和所属订阅隔离；直接远程引用不写入公共产物表。
- 删除订阅或移除专属引用时清理加密结构版本中的旧正文、原文绑定和无引用快照。
- 删除并重建同 ID、token 重置、用户停用、模板引用删除、会话注销/失效均阻止在途旧正文下发。
- 仓库停用、删除、索引文件移除后旧资源失效；停用后立即重新启用不能恢复旧请求、首次公共编译或缓存绑定。
- 原文请求因并发限制排队，在资源删除后才开始拉取，也不能遗留私有正文与绑定。
- v24 → v25 清理含旧 URL 的渲染缓存及旧公共远程产物，保留当前用户 token；重复启动幂等。
- 保留节点流量头、代理链服务端处理和可读 rule-provider 名称。

使用 Codex 内置浏览器和 `packages/server/test/manual-query-resource-routes-server.ts`。环境为 `127.0.0.1:18727`、内存数据库、虚构节点/规则正文和确定性仓库索引。没有使用生产数据，没有访问真实上游，没有安装或调用独立 Playwright/浏览器。

| 场景 | 实际结果 |

## 迁移注意

这次为不保留旧入口的地址迁移。部署后客户端需要重新复制主订阅和独立资源链接，再刷新主订阅获取新 provider 地址；用户 token 本身保持不变。模板不发行 token 地址。公共资源的定义与访问 token 解耦，删除某个订阅不会删除其他用户仍可访问的公共规则。
