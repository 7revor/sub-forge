## 布局与交互

- 12 种处理类型均覆盖：无用节点过滤、正则过滤、协议类型过滤、正则改名、正则删除字符、前后缀、旗帜、名称排序、正则优先级、去重、快捷设置、脚本。
- 参数区及其中 YAML 编辑器的计算背景色为透明；重复参数复用规则集卡片，简单选择为带标签的单选项，无灰色底块。卡片沿用 8px 圆角、浅边框与 13px 正文，紧凑行保持至少 50px。
- 处理器与参数添加入口均在所属列表之前。菜单采用四个有分隔线的分组，项目相对组标题缩进。
- 桌面 1440×1000，所有参数区无横向溢出；390×844 下全部 12 种的参数宽度与滚动宽度均为 320px，文档宽度与视口均为 390px。
- 新增/删除正则与规则、删除至空列表再添加、非法正则 `[` 提示、空输入保留 placeholder 均通过。
- 优先级通过键盘 Space / ArrowDown / Space 重排；修改输入后点击外部回到总览，失焦提交保留。
- 旗帜、排序、去重的单选项可切换；协议类型的无底色复选项和顶部自定义协议表单均显示正常。
- 快捷设置 udp 先清空再选关闭，false 正确保留；其他字段新增 x-zero=0，数值 0 正确保留。保存并刷新后优先级顺序与 udp=false 回显正确。
- 添加处理器菜单打开/退场保持当前选择，通过菜单新增处理器后选中新步骤。参数下拉的 Portal 选择不会触发外部取消。
- 浏览器控制台没有 warn/error。
