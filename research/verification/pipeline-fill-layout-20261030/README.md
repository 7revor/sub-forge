# 处理链工作区布局验收（2026-10-30）

## 实现

- 订阅源使用导航右侧完整宽度；宽屏基础设置的名称和地址并排。
- 下方处理链和预览改为约 28% / 剩余宽度的等高双栏，撑满页面剩余高度；步骤、节点各自滚动，添加按钮固定在左栏底部。
- 短屏保留 360px 可操作高度，允许外层页面滚动；小于 1024px 上下排列，表格在自身区域横向滚动。
- 隐藏默认自动“去重 · 加序号”的列表项、详情入口和自动步骤标签。后台兜底与最终输出不变，显式添加的去重步骤仍保留。
- 总览与普通处理器行统一至少 66px。

设计沿用项目既有配色：背景 #f5f6f8、面板 #ffffff、正文 #15181d、边线 #e3e6eb、品牌蓝 #2952cc、成功绿 #1d7a46。正文沿用 Inter / 中文无衬线，节点和规则用等宽字体；所有内容左对齐，保留现有标题层级，不增加装饰或额外动作。

## 验证

全项目类型检查、前端生产构建通过；构建保留既有体积警告。最终前端测试 39 个文件、325 项通过、2 项跳过；核心处理链专项 14 项通过，包含自动去重后名称唯一。未修改渲染算法、服务端接口、数据库及正式示例种子。

仅使用 Codex 内置浏览器与 `manual-resource-refresh-server.ts` 内存数据，监听回环地址 18893，虚构 3/80 个节点、4/20 个处理器；未访问截图中的真实订阅地址。
