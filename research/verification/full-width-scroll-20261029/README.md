# 右侧全宽滚动验收

2026-10-29，基于 `main@0fb5241`，使用 Codex 内置浏览器与独立临时数据库验收。

## 改动

- `page-layout` 铺满右侧区域；页头及普通独立面板保留 1280px 最大宽度。
- `PageScroll` 外层承载滚动，内层内容限宽居中，留白属于滚动区域，底部延伸到视口边缘。
- `Card scroll` 复用同一 wrapper，列表及节点编辑表单不再在卡片正文内另设页面纵向滚动；卡片内搜索、表头、编辑视图切换随面板滚动，页头操作仍固定。
- 表格横向滚动、代码预览等局部滚动与规则仓库的独立分栏仍由各自组件负责。

## 验证结果

- `pnpm --filter @sub-forge/web build` 通过，包含 TypeScript 检查；Vite 提示既有的大包体积警告。
- 1800×950：规则集 wrapper 与右侧 main 同宽 1584px，内容宽 1280px；wrapper 底边为 950px。
- 鼠标位于 panel 右侧留白处滚动：wrapper 的 scrollTop 从 0 增至 770.5；文档 scrollTop 为 0，标题 y=60.75、导航 y=0 保持不变。
- 35 项本地分组列表：复用全宽 wrapper，侧边留白滚动后 scrollTop=950，文档仍不滚动。
- 390×844：规则集、列表、节点编辑及账户页未撑宽文档；规则集和列表 wrapper 宽 390px，底边为 844px；表格横向溢出限制在卡片内。
- 节点编辑页：可用滚动高度 679px，内容高 1348px，无额外文档滚动。
- 临时验收服务已停止；原有 5173/8080 服务未改动。没有向实际业务数据库写入验收数据。
