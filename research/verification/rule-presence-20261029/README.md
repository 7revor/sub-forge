# 规则存在即生效验收

日期：2026-10-29。用户要求规则集增强、模板、订阅规则取消启用开关，并确认旧停用项移除、保持当前输出。使用 Codex 内置浏览器、独立 worktree、内存数据库和虚构账号，不访问真实订阅或外部规则上游。

## 行为

- 规则集来源、模板规则、独立订阅规则、绑定前置规则均无启用 Switch。模板同时回收启用列；不再使用停用样式或停用标签。
- 规则存在即参与输出，不需要时删除。排序、出口和 no-resolve/src 等选项保留。
- SQLite v17 在事务中删除规则及规则来源的旧 enabled:false 项，其他项清除 enabled。处理全部模板版本及两种订阅模式，先展开遗留覆盖层以保留锚点语义。文档归属、更新时间、模板版本、订阅令牌与历史资源保留，旧备份不改写。
- 规则集保存、模板自检/发布、订阅保存/预览、种子导入执行相同清理。旧 YAML 的 disabled 注释对应条目不再导入，导出也不再带启停标记。
- 仓库与处理链处理器自身的启停机制不属于此次移除范围。
