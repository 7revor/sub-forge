## 实现

- 订阅名称、可选多行备注、模板设置采用上下结构。
- 模板设置默认显示关联摘要，按需展开页内编辑。保留跟随更新、复制后独立维护、解除关联及迁移映射；映射列表限高，避免组较多时撑长整页。
- 应用模板仅改变订阅草稿，保存后生效。失败保留选择、支持重试；处理中更改草稿、收起重开或组件卸载后，不应用过期响应。
- 备注可新建、更新、清空；模板转换保留备注，客户端输出不包含管理备注。
- 订阅链接、复制操作和最近访问状态合并到页头，移除底部独立链接卡片；原导航改为“输出与访问”。

## 内置浏览器验收

仅使用 Codex 内置浏览器。通过 `manual-subscription-basics-server.ts` 启动内存数据库、虚构用户与节点，禁止访问上游，生产构建保留项目的 StrictMode。使用独立的 `subscription-basics.localhost:18649` 域名隔离同机测试会话；未接触生产数据。

通过的场景：

1. 多行中文和 emoji 备注保存后刷新回读，新建时填写备注，保存后清空备注。
2. 模板设置在页内展开，不出现业务弹窗；跟随更新、复制独立、解除关联均可应用。
3. 更换模板自动匹配唯一同名组，清空迁移目标后禁用应用，重新选择后可应用；原节点填充和备注保留，保存刷新后新模板仍有效。
4. 取消模板选择不产生外部修改；应用后“放弃修改”恢复已保存配置。
5. 临时模拟离线，应用失败仍保留原选择，恢复网络后重试成功。
6. 模拟延迟响应，期间修改备注，过期转换被拒绝并显示重新应用提示；收起后重开不会被上次响应改变。
7. 顶部链接始终可见，复制按钮显示“已复制”；浏览器会话剪贴板读取返回空，未据此声称实际剪贴板内容核对通过。
8. 390×844 窄屏中名称、备注与模板设置正常换行；页面滚动宽度为 390，无横向溢出，顶部完整链接可换行。
