## 实现与保留边界

- 管理员唯一资源缓存周期，默认 24 小时；旧节点、规则来源和订阅的独立周期移除。
- 单资源一份成功内容；失败保留原文和真实成功时间，下次尝试按最近尝试加系统周期，手动刷新绕过等待。
- 后台每分钟检查到期资源；节点、组合、规则各刷各自依赖，订阅递归去重刷新后重建配置。
- 文本统一托管，合适的 MRS 校验后原字节托管；SRS 明确报错。保留 last_good 和最多 32 个结构版本保障旧客户端资源一致性。
- 管理端不保留时间缓存；挂载、聚焦、联网和 SSE 变更重读，断连提示重连，草稿不被覆盖。
- 仓库索引使用同一周期；Git 成功索引后回收旧引用及不可达对象，失败保留旧提交。未引用的仓库文件不整库预抓取。
