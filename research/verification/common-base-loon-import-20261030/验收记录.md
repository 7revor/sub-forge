- 新增 Loon 完整配置导入页与事务式创建接口，覆盖基础设置、节点、远程来源、NameRegex、策略组、两跳命名链和规则。预览不联网；保存失败整体回滚。
- Loon 完整输出生成 `[Proxy Chain]`。命名链使用独立落地副本，保留原出口；复用已有引用和环检测。
- 规范 VLESS/VMess SNI，按目标端处理 block-quic。Loon 可用性阈值与单次测速超时分别保存。

详细映射、优先级和限制见[客户端转换说明](../../../docs/19-client-conversion.md)。

## 明确未完成的外部验证与能力边界

- 未运行 Loon / Stash 官方真机配置导入、启动、DNS 或实际代理转发；本机没有相应官方校验器。远程真实订阅内容也未拉取。
- 本轮没有重跑全部弹窗的所有关闭入口、嵌套、无动画和布局高度浏览器矩阵；相关运行时未修改，已有架构与生命周期单测通过，浏览器仅检查本轮涉及的草稿/关闭/导航行为。
- 通配域名、TUN、API、skip-proxy、STUN、接口和 FakeIP 范围等仍按原生端维护；不会声明为公共等价转换。
- Loon ip-mode 同时影响连接；公共 DNS IPv6 意图不能直接替换它。显式原生覆盖会提示语义差异。
- 当前完整导入仅适配两跳、静态落地链。多跳、动态落地、缺少结果的被引用 NodeSelect 等明确阻止导入。
- Mihomo / Stash 不把节点 block-quic 自动改写成全局 UDP 443 拒绝规则；需要阻断时当前目标报错。Surge 仍不支持 VLESS / Reality。

验收临时 HTTP 服务仅监听本机回环地址，完成后停止；临时启动脚本不纳入提交。
