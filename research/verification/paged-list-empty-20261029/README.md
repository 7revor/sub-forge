# 分页列表公共 blank 复核

日期：2026-10-29；基线：`main@e231808`；分支：`codex/paged-list-empty`。

## 源码结论与修改

- 模板分页列表已直接调用公共 `Empty`，`ui.tsx` 仅转导出该组件，没有独立空框实现。
- 配置订阅、订阅源、本地分组、组合、规则集和基础设置预设均通过 `DocList` 调用同一个 `Empty`；规则仓库搜索同样使用它。
- 遗漏的是 `AsyncSelect` 的分页候选无结果提示：由普通文本改为公共 `Empty size="compact"`，覆盖仓库关联与模板规则集引用。
- 规则仓库仅在成功取得空结果时显示 blank，避免请求失败也显示“暂无可用索引”。后端与领域模型没有变化。
