按用户此前明确授权直接在 main 修改。

## 实测

仅使用 Codex 内置浏览器，隔离内存数据，未操作生产数据。

- 桌面 1280px：普通规则与 MATCH 均为 946×50px，13px 正文、1px 边框、10px 圆角；模板、独立订阅、绑定订阅主规则一致。
- 窄屏 390px：普通规则与 MATCH 均为 320×90px，名称/出口对齐，无页面横向溢出。
- 鼠标拖动远程规则到本地规则之后，顺序由 remote/local 变为 local/remote；MATCH 始终在排序列表外、最后一张卡片，排序按钮数量为 0。保存后顺序正确回显。
- measurements.json 中绑定页面也记录了折叠前置列表；前置规则容器更窄，其宽度不参与主规则卡片对比。
- web 生产构建（含类型检查）通过；保留既有 bundle 体积提示。SharedRoutingEditors 与 TemplateFields 共 7 项测试通过，git diff --check 通过。
