## Codex 内置浏览器验收

仅使用 `@Browser`，未安装或调用外部 Playwright/Chromium。真实应用使用 `packages/server/test/manual-rule-cards-server.ts`：内存数据库、虚构规则正文和模拟仓库索引，端口 5237，不读写生产数据。测试账户由既有隔离 fixture 创建。

通过场景：

1. 模板、增强集合和订阅进入页面不发送仓库匹配请求、不出现标记。
2. 模板本地多行编辑、应用与保存成功，条数随内容变化；订阅 3 条保存后重新进入仍完整回显。
3. 本地空值应用被阻止，取消再打开恢复原内容；弹窗取消不会改列表草稿。
4. 模板手动检测一次请求；返回列表再进入标记消失，未出现额外检测。
5. 新增远程输入 URL 时不检测；点击应用后只检测新增地址一次。模板和增强集合两条独立实现均已验证。
6. YAML 输入时不检测；应用后两个 URL 在同一次批量请求中检测，命中标记出现，原 URL 未自动替换。
7. 点击匹配建议中的“关联仓库文件”才替换来源，位置和出口保留；增强仓库文件可在弹窗换选，保存成功。
8. 增强来源正文打开独立预览，关闭回到原列表，下方持续为合并结果；不再先切全局再切来源。
9. 绑定订阅的模板规则显示锁定/跟随模板，不能编辑或删除；展开前置规则可使用同款多行弹窗。
10. 订阅键盘拖动将包含 3 条规则的整张本地卡片移至首位，内部条数保持，保存成功；关联检测标记随远程卡片移动。
11. 390×844 窄屏页面 `scrollWidth === clientWidth === 390`，弹窗标题和底部按钮完整可操作，多行输入可滚动。已恢复浏览器临时 viewport。
12. 实测按钮外框 40×40、图标 18×18。发现初版 padding 挤窄图标至 10px 后已修正并重新测量。增强多行保存后显示禁用的“已保存”，无虚假未保存状态。

请求计数旁证：首轮模板手动一次、新增一次、YAML 一次批量、增强手动一次；最终进程中订阅手动 #1、增强新增 #2、订阅手动 #3。页面加载、输入、保存、排序和重新进入期间未出现额外检测请求。

验收种子最初缺少订阅 refPolicy，且独立 config 错误包入模板元信息，分别造成页面/保存失败；修正隔离 fixture 后重跑通过，不涉及生产数据。网络失败与请求乱序未额外做浏览器故障注入；页面 epoch 与单 URL 版本保护已进行代码审查，不将未执行故障场景记为通过。外部客户端条件跳过的用例同样不记为通过。
