日期：2026-10-30。代码在 `codex/group-dialog-settings` 工作树完成。已兼容工作期间 main 的刷新进度、规则卡片、多行规则、字段顺序及提示文案改动。

## 实现与规范

- 业务窗口统一 `createModal(...).show(data)`，简单交互统一 `Frame.modal.confirm / alert / success / error / prompt`；共享一个 Router、QueryClient 内的 ModalRoot。
- 每个会话输入、输出深拷贝；草稿与外部数据隔离，确认 Promise 返回后写回。取消不提交，新增取消不插入列表。
- 关闭保留标题、表单、校验和查询展示，待 Radix Content 实际卸载才销毁并结算；无固定延时、无 DOM 复制、无独立 React 根。
- 异步提交防重、失败保留草稿与错误；嵌套和连续 show 独立结算并恢复正确焦点。
- `AGENTS.md`、`CLAUDE.md`、`docs/18-unified-modals.md` 明确禁止其他弹窗封装；架构测试限制底层 Dialog、原生提示、业务 JSX 弹窗和自行挂载。
- RuleEditShell 仅为统一会话内部的表单布局，不是另一个弹窗运行时。

## Codex 内置浏览器

仅使用 @Browser，未安装或调用独立 Playwright/Chromium。临时 Vite 18644 与内存后端 18643 使用虚构节点、规则和账号，不连接真实上游。

| 场景 | 结果 |
| --- | --- |
| 策略组修改名称并展开高级设置后取消 | 外部名称不变，重开恢复原值 |
| 策略组保存 / 新增后取消 | 确认才写回；新增取消不增加列表项 |
| 确认、取消、关闭按钮、Escape、遮罩 | Promise 分别返回 confirmed / cancelled，无空白退场 |
| 同一窗口换不同数据重开 | 标题和说明更新，不沿用旧草稿 |
| 保存失败后重试 | 草稿、错误留在原窗；成功退场仍保留错误区域与高度 |
| 动态查询关闭时清空查询值 | 保留最后一次打开时的正文 |
| 子弹窗保存、父弹窗路由离开 | 子结果只写父草稿；父返回 navigation 取消 |
| 连续打开两个提示 | 顶层关闭后下层继续显示，焦点位于下层窗口 |
| StrictMode / 无动画 | 会话只结束一次，无动画立即完成，无悬空结果 |
| 订阅独立策略组取消 | 名称和 Provider 成员均未修改外部，页面仍为已保存 |
| 绑定模板高级设置 | 名称、类型、测试和筛选字段禁用，成员仍可填充 |
| 模板关联确认 | 只应用订阅页面草稿，显示有未保存的修改 |
| 新版规则来源编辑 | 取消后多行内容恢复；保存后外部显示两条规则，预览一致 |
| 新版模板本地规则 | 保存后新增卡片；继续编辑取消离开，保存并离开成功导航 |
