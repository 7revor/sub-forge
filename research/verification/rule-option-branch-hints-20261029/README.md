# 规则文件来源说明验收

日期：2026-10-29。

## 展示规则

- 根目录文件的第二行仅显示仓库名，不保留 `/` 占位或多余分隔符。
- 单分支匹配结果显示 `仓库名 · 父目录/`；路径不重复文件名。
- 同仓库的完整匹配集中出现多个分支时，显示 `仓库名 * 分支 * 父目录/`；根目录显示 `仓库名 * 分支`，不使用“分支：”前缀。
- 分支统计在数据库内针对完整匹配集完成，随后取当前页；前端继续按 30 项分页加载。
- 不同仓库的分支互不影响；搜索缩小到单分支后隐藏分支信息。文件名和实际父目录的命中词继续高亮。
