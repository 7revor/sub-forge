# 全局直接使用 shadcn 官方组件验收

日期：2026-10-30。此记录替代上一轮手动适配 Radix 动效的实现说明，历史验收记录保留。

## 实现与来源

- 官方 `new-york-v4` 注册表的 Dialog、AlertDialog、Select、Popover、DropdownMenu、Command、Sonner、Button 共 8 个组件直接落盘，只把注册表内导入改为本地相对路径。
- 每个组件逐字对照下载的源码，通过；URL 与原文 SHA-256 见 `packages/web/src/components/ui/registry-sources.json`。
- 删除原 Modal 与 primitives/overlays；23 处业务弹窗直接组合官方 Dialog/AlertDialog。没有业务动画类、关键帧、退场计时器或自写焦点恢复。
- 单选保留业务空值选项编码，多选使用官方复选菜单；自由输入候选与异步搜索使用 Command + Popover。分页、搜索与提交逻辑仍属于业务代码。
- 官方 neutral 主题使用标准变量，旧页面文字灰色和品牌色改为独立名称，避免覆盖组件默认颜色。原静态表单、卡片等不是本次弹层迁移范围。
- 后端接口、领域模型、示例种子未改变；外部画布未编辑，待同步登记 docs/11、docs/13。

## 限制

覆盖全部公共弹层类型及代表性业务入口，未逐一点击所有业务实例。没有验证真实备份恢复或公网节点连通性。组件默认焦点行为未自行覆盖：提交按钮被禁用时触发异步错误，错误关闭后的焦点可回到 body；下层确认保持可操作。默认动效完全遵循官方源码，没有额外减少动态效果覆盖。

## 启动故障

合并后主工作区缺少新增依赖，且 node_modules 的虚拟存储目录指向另一个旧 worktree。已按锁文件离线重装到主工作区自身 node_modules。原 Vite 进程仍持有旧依赖解析，产生重复 React 的 Invalid hook call；最终代码合入后重启开发服务并重新验收。
