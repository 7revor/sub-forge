# 主列表刷新时间与弹窗底部统计验收（2026-10-30）

## 变更

- 节点订阅、组合、增强规则与配置订阅主列表增加“上次刷新时间”，紧邻操作列之前；节点原“上次拉取”列移除。
- 复用资源状态接口 `lastSuccessAt`，失败尝试时间不替代成功时间；多资源取最近一次成功时间，悬停展示各项成功时间，失败仍由资源缓存状态标明。
- 无成功记录与纯本地规则显示 `—`，不写入伪时间。
- 节点、规则及订阅共用刷新弹窗：删除客户端更新说明，进度和成功/失败统计固定放在资源列表、订阅生成状态之后。
- 核心模型、数据库和示例种子不变，后端接口无需新增字段；补充成功时间不被失败覆盖的服务端验证。
