日期：2026-10-30。基于当前工作树的生产构建，仅使用 Codex 内置浏览器与内存数据库夹具。

## 实现

- 从 shadcn/ui 官方 new-york-v4 注册表引入 Sidebar 静态结构、分组和菜单组件；来源及原始源码 SHA-256 记录在 `packages/web/src/components/ui/registry-sources.json`。
- 只保留固定侧栏（`collapsible="none"`）所需部分。移动端沿用页内展开，不引入 Sheet，遵守全站统一弹窗运行时约定；未新增依赖。
- 菜单分为工作台、节点资源、规则资源、系统管理。区分配置订阅与订阅源，明确本地节点与节点组合的含义。
- 使用图标、组间留白、系统管理分隔线和独立账户区区分信息层级。桌面宽度 232px，菜单行高 32px；窄屏菜单行高 44px。

1. 桌面 1280×720：通过。四组及所有管理菜单完整显示，侧栏内容高度 515px，无额外导航滚动；账户与退出入口固定在底部。见 `desktop.jpg`。

4. 手机菜单点击系统：通过。跳转 `/system` 后 `aria-expanded=false`，菜单内容高度归零。
5. 键盘：通过。Tab 可从用户入口移动到系统入口，显示 2px 浅蓝焦点环；Enter 可进入系统页。
6. 普通用户：通过。独立内存夹具中仅显示前三组，模板、用户、系统入口均不渲染。见 `ordinary-user.jpg`。
