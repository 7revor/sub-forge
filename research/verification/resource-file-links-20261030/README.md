| 场景 | 结果 |
| --- | --- |
| 首页配置、节点订阅 | 复制按钮可用，显示“已复制”；节点源模拟解析失败时仍能复制托管地址 |

| 模板远程规则 | 新标签页显示原文，URL 带当前 token 与内容摘要 |
| 模板静态规则 | 保留弹窗，标题和正文正常，关闭后返回原页面 |
