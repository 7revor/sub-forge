## 合并前二次审查

本次先将最新 `main@38009e7` 整合进功能分支，仅两份 README 的追加内容发生冲突，已保留双方文档。

审查发现并修复：

1. 普通 HTTP 上下文缺少 `crypto.randomUUID()` 时测试按钮会在请求前抛错。改为 `crypto.getRandomValues()` 生成 128 位随机标识，生成过程也纳入错误展示；增加模拟无 randomUUID 上下文的回归测试。[接口限制依据](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/randomUUID)
2. 服务退出时调用了未等待的 `nodeProbe.close()`，清理失败会产生未处理的 Promise 拒绝。改为单次退出流程，等待所有任务完成后显式报告失败；探测服务关闭同样等待全部任务清理。
3. 内核版本接口持续返回非成功状态时，原启动期限只在请求抛错时判断。现在无论响应状态如何都会检查启动期限，增加持续 HTTP 503 的回归测试。
