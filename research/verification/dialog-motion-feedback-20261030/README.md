# 弹窗动效与操作反馈验收

日期：2026-10-30（Asia/Singapore）。分支：`codex/dialog-motion-feedback`，基线：`f8fa180`。

实现提交：`cd6f448`（统一动效与确认框）、`60be77d`（精简冗余反馈）。

## 改动

- 通用弹窗与错误弹窗采用 180ms 入场、160ms 退场，遮罩淡入淡出，面板轻微位移与缩放。关闭时保留最后一次内容，避免先清空再退出；重复打开会取消旧卸载计时器。
- 修复含 autoFocus 的弹窗关闭后焦点未返回触发按钮的问题；正在退场的弹窗不再参与顶层键盘处理。
- 下拉选项、规则诊断浮层、处理器菜单与必要成功通知采用 140ms 入场。系统选择减少动态效果时禁用上述动画并立即安排卸载。
- 订阅链接删除、备份恢复使用通用确认弹窗，保留原有危险操作确认。
- 正常返回表单、添加字段、撤销及登录退出不再发全局成功通知；原始配置转换时的忽略说明显示在编辑器内。复制成功在按钮上显示“已复制”，保留复制失败提示。
- 保存、删除、请求失败、导入结果及带撤销入口的通知继续保留。
