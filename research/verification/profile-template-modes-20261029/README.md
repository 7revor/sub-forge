# 模板绑定、独立配置及旧数据迁移验收

日期：2026-10-29。工作分支：`codex/template-subscription-modes`，基于 `3a0af58`；未合并、未部署，不读取或修改生产数据库。

## 实现范围

- 绑定订阅只保存模板 ID 与按稳定组 ID 组织的追加成员；始终读取最新模板。独立订阅保存完整分流配置，初始化模板仅作来源说明。
- 双向转换与换模板先生成草稿；明确映射成员及代理链/节点回退引用，展示替换或移除内容，统一保存才落库。保存检查订阅 revision 和模板版本。
- 绑定冲突禁止强制发布；发布影响分析期间有模板或绑定订阅并发变化时拒绝发布。异常渲染沿用上一份成功输出。
- 数据库 v16 事务迁移、加密原文备份、原有链接与历史资源保留；缺失模板版本或无法等价迁移时整批回滚。只读迁移预检在临时一致性副本上执行。
- 后台重新获取不覆盖未保存的模式转换/编辑；保存期间继续输入时保留后续修改并接收新 revision。

新增和扩展的回归覆盖：

1. v15 持久化数据库中的纯追加、完整覆盖、锁定版本、无模板、孤儿项；比较迁移前后有效 groups/rules/final 和最终 YAML（仅归一化结构版本摘要），检查所有者、更新时间、原始加密备份、令牌、last-good 和重启幂等。
2. 只读迁移预检保持源库版本/数据不变且不输出令牌；缺失模板版本时整批回滚。
3. 模板改名与规则更新同步，追加成员保留；旧资源 URL 可用；解除绑定后后续模板更新不影响独立配置。
4. 删组、模板与追加成员合并成环禁止强制发布；异常存储版本导致渲染失败时 last-good 兜底。
5. 越权字段、旧形状回退、错误归属、过期 revision/模板版本、影响检查期间并发修改均被拒绝。
6. 重新绑定必须明确映射，转换接口不写库；独立规则集仍能更新且被引用资源不能删除。代理链节点及引用在解除/重新绑定后保留，最终输出仍含 `dialer-proxy`。
7. 示例种子覆盖两种模式，原 `demo` 的筛选、成员、规则、最终出口及 `demo-token` 保持一致。
8. 编辑器适配保持组顺序、规则选项、引用、最终出口；反复保存不累加成员；后台刷新及保存期间输入不丢草稿。

代理链回归中确认现有实际渲染要求相关节点集先加入订阅，未扩大为隐式加载未加入的节点集。断言同时按整组 provider 的 `override.dialer-proxy` 输出位置校准。
