# 基础设置编辑工作区

## 参考与取舍

已搜索并通过内置浏览器查看两份官方界面：
- [Vercel 环境变量设置](https://vercel.com/docs/environment-variables/managing-environment-variables)：设置对象与输入区域就近放置，字段按任务分组。
- [Cloudflare Workers Quick Edit](https://blog.cloudflare.com/improved-quick-edit/)：原文编辑器使用紧贴内容的文件页签、行号，工具区域不占据正文宽度。

本页只有四个内核、每个内核三个固定原文槽位，不需要文件树。采用单编辑工作区，不复制完整 IDE 或增加新的设置能力。

## 设计计划

- 色彩沿用项目：正文 #15181d，次要文字 #5b6270，线条 #e3e6eb，页面 #f5f6f8，编辑区 #ffffff，强调 #2952cc。
- 字体沿用 Inter / 苹方；原文与行号使用现有等宽字体。字段标签 12.5px，正文 13px，段落标题 15px。
- 基础设置使用完整的白底面板，基本字段与配置追加共用面板；页面外围灰底、工具条浅灰底、原文白底。名称、流量来源、备注同一基线。
- 配置追加使用清楚的段落边界；内核选择为紧凑切换栏。
- 编辑器自身只有一层外框：公共配置与客户端原文用文件页签切换，编辑区占满宽度。取消左侧栏、重复标题、说明段和四处散落的状态标识。
- 客户端原文仍可留空；切换内核、槽位及停用均不改写数据。保留多选流量逻辑。

```text
名称                         流量 / 到期信息               备注
[                      ]    [多选                    ]   [                    ]

配置追加                                                        [启用开关]
[Mihomo | Surge | Stash | Loon]
┌ 内核公共  │ FlClash │ Clash Verge Rev ─────────────────────────── YAML ┐
│ 1   mixed-port: 7890                                                 │
│ 2   dns:                                                            │
│ 3     enable: true                                                  │
└─────────────────────────────────────────────────────────────────────┘
```

复核：区分业务层级与原文槽位，不把只有三项的导航做成占据整列的卡片；原文区是主体，空白和边线只用于划分实际操作区域。

## 验收结果

- 前端类型检查及生产构建通过；保留既有大包提示。
- 前端单测 350 通过、2 个已有跳过。
- 在内置浏览器验证公共 / FlClash / Verge Rev 页签、左右方向键与跨内核切换。
- 未完成的 YAML（`dns: [`）可原文保存；切换内核、停用再启用后保持原样。
- 22 行示例配置的行号与正文纵向滚动保持对齐；行号仅依据换行生成，不解析配置。
- 将客户端原文改为有效配置后保存并刷新，公共与客户端配置分别保留。
- 流量多选依然可以连续选择两个节点订阅并保存回显。
- 390×844 下，表单纵向排列，三个配置页签可直接点击；代码长行在编辑器内部滚动，面板没有横向溢出。
- 最终桌面截图保留灰色页面、白色设置面板和浅灰工具栏；手机截图展示同样的底色与层级。
- 临时服务只使用内存数据库、虚构账号与固定上游。验收后停止服务、关闭临时标签页并恢复默认视口。
