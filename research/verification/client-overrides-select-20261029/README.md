# 客户端改写 Select 与间距验收

日期：2026-10-29。

- 改写类型使用公共 Select，下拉选择替换、丢弃或追加。
- 宽屏将改写类型、客户端、平台、匹配内容排在同一行，标签与控件统一对齐；删除位于行尾，移除多余序号。
- 窄屏改写类型独占一行，客户端与平台并排，匹配内容另起一行；目标规则标题与输入左对齐。
- 主间距为 12 px，目标规则标题与表单间距为 8 px，收紧底部留白；不改变数据结构与执行语义。

## 已验证
