# 三页卡片尺寸与出口菜单验收（2026-10-30）

按用户此前明确授权直接在 main 修改。沿用主分支现有规则编辑/保存行为，没有部署或修改生产数据。

## 实现

- 增强集合来源、模板、独立/绑定订阅共用 RoutingCard：桌面基准高度 50px、正文 13px、类型图标 16px / 底座 32px、操作图标 14px、编辑/删除按钮 28×32px。
- 原策略组表格行改为同款白底、浅边圆角卡片，长名称/成员截断，保留拖动、隐藏开关和独立编辑。删除开关旁“隐藏”文字，保留中文无障碍标签和悬停说明。
- 本地规则卡片删除“本地规则 · ”前缀；无名称的增强本地来源展示首条规则内容。输入弹窗和添加按钮仍使用准确的类型名称。
- 规则出口与 MATCH 使用 136px 区域内的文字和一个箭头，点击官方 DropdownMenu 单选菜单；不使用 SelectTrigger，不画输入框边框/阴影。空值显示中文提示，丢失引用显示真实信息，选中项有标记，键盘焦点可见。
- 窄屏保留字号和按钮尺寸，将成员、数量及出口移至第二行，避免长内容挤压操作。
- 生产 API、领域模型、数据库、示例种子不变。隔离验收脚本增加 --layout，提供长/短名称和隐藏状态样本。

- 390px 窄屏：三页和绑定模式无横向页面溢出；长名称保留省略号，按钮与隐藏开关可见；规则和成员信息换行。

- 绑定模式：策略组只能打开节点填充，隐藏开关禁用，规则无编辑/删除/出口操作；前置规则继续使用相同卡片和菜单组件。
- 中途菜单关闭导致一次选择未命中，以及一次菜单容器 press 超时；读取当前 UI 后分别重新打开菜单、使用内置浏览器原生 Escape 完成，最终断言通过。
