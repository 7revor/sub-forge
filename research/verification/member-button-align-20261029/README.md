# 添加成员按钮居中修复

日期：2026-10-29；分支：`codex/member-button-align`。基于当时 main 的 dbba184，在独立 worktree 中修改。

问题来自按钮标签的嵌套 inline-flex：文字基线为外层行盒保留额外空间，使加号与文字中心比按钮和箭头偏上 1.4375px。

将动作标签改成块级 flex，内容与加号对齐并居中，加号禁止收缩。按钮尺寸、选项、成员添加逻辑均保持原样；普通出口下拉不受影响。

## 验证

- 使用 Codex 内置浏览器、本机临时数据库和独立测试域名验收。
- 修复前加号与标签中心偏差为 -1.4375px；修复后加号、标签、箭头相对按钮中心偏差全部为 0px，详见 measurements.json。
- 下拉可正常展开；选择 REJECT 后成员数从 1 变为 2，选项添加成功并自动收起。
- 前端类型检查和生产构建通过；构建保留已有的大资源包提示。
- 未为这一处样式修改新增单元测试；测试服务在完成后停止。
