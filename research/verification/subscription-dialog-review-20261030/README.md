# 订阅编辑弹窗复查与验收

日期：2026-10-30。基线：`9c05560`。工作分支：`codex/member-chain-editor`。

## 修正内容

- 策略组弹窗固定为 800 px 上限，模板与前置弹窗固定为 680 px 上限，均预留视口上下边距；正文独立滚动，底部操作固定。
- 模板关联使用单次底部确认，绑定、复制与解除关联使用同一套操作位置。仅为现有填充及有效引用要求迁移映射；同 ID 或唯一同名组自动匹配。
- 模板组的隐藏状态显示禁用开关，类型、lazy、排除协议等自定义控件明确接收 disabled。
- 空选择使用真正 placeholder。模板未设置的参数保留空值并说明含义；真实设置完整回显。
- 成员空状态移除虚线边框。全部节点来源为 Provider 时优先显示 Provider 引用区；固定成员单独计数。无 Inline 时禁用该分类，显示原因。
- 会循环引用的策略组显示为禁用候选并解释原因；搜索无结果有明确提示。
- 单节点前置编辑复用策略组弹窗底栏，显示具体落地节点名称。取消整个弹窗同时撤销成员与前置修改。
- 节点查询错误改为区域内提示及重试，避免叠加全局错误弹窗。
