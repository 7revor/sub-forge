# 刷新弹窗固定列表验收（2026-10-30）

目标：不改变弹窗现有尺寸规则，打开时直接展示全部待刷新子规则，刷新后原位改变状态，避免按完成顺序追加卡片导致高度跳动。

## 实现

- 服务端创建任务时预填全部去重资源，按固定索引更新等待、执行中、已完成和中断状态；未完成项不填写 `ok`，不计作失败。
- 前端取得任务列表后打开弹窗，固定行数和顺序；说明始终显示，订阅生成状态预留位置。长错误单行省略，悬停可查看全文。
- 保留官方 Dialog 的宽度、最大高度、间距和动画；兼容旧任务的完成结果。
- 核心 IR、数据库表结构、配置种子与实际规则渲染格式不变。

| 场景 | 结果 | 弹窗高度 |

| 5 条规则刷新开始 | 4 项刷新中、1 项等待，全部已显示 | 576px |
