# 节点预览与默认全部节点验收

日期：2026-10-30。分支：`codex/node-preview-filter`，基于 `65fb46d`。

## 行为

- 节点来源的名称与数量区域可点击打开统一节点预览弹窗。
- Provider、Inline 的前置与落地均在选择节点集后展示全部节点；筛选为空，placeholder 为“全部”。输入正则缩小范围，点击列表可精确指定节点，清空筛选恢复全部。
- 前置延续首个匹配节点的解析方式，列表标注“当前采用”；全部落地包含后续新增节点。
- 历史正则、排除条件和精确名称保留。取消不会写回订阅草稿。
- 服务端在完整节点列表上筛选后截断展示；超过 5000 个节点后的匹配仍可找到。列表分批展示，计数覆盖完整匹配结果。

## 自动检查

- 前端：43 个文件，352 项通过、2 项既有跳过；含统一弹窗架构及控制器生命周期测试。
- 后端：代理链诊断与分流配置 11 项通过；补充大节点集后，代理链诊断与预览接口 29 项通过（两次运行包含重复的代理链用例）。
- 新增回归覆盖 Provider / Inline 空前置筛选的保存、读回与实际渲染，空落地筛选包含后续新增节点，局部筛选缩小范围，空精确名称仍被拒绝，以及 5002 个节点的筛选与排除。
- 全项目类型检查通过；最终前端生产构建与后端类型检查通过。构建仍有大分包体积提示。

## 内置浏览器

使用 Codex 内置浏览器和 `manual-member-chain.ts` 内存服务，账号与节点均为虚构数据。

1. 点击节点来源预览，默认全部、正则筛选、关闭重开恢复全部。
2. Provider 前置 / Inline 落地，以及 Inline 前置 / Provider 落地的默认列表、占位文字与应用按钮。
3. 双侧正则筛选、点击精确节点、清空恢复全部、非法正则阻止应用、同源整集循环阻止应用。
4. 应用、保存、刷新、重开后空筛选保留；取消及 Escape 后重开仍为已保存数据。
5. `dialog-exit.html` 在 StrictMode 下检查取消、关闭按钮、Escape、遮罩、嵌套预览、路由离开、失败重试、无动画关闭与确认。8 项动画检查每项采样 120–121 帧，标题、正文、输入值与布局高度保持一致。无动画时 Promise 正常结算，无残留弹窗。
6. 最终服务端筛选版本重新执行节点预览及生命周期验收，浏览器无控制台错误。

截图：`chain-all.png`、`node-preview.png`。逐帧及 Promise 记录：`modal-lifecycle.txt`。

节点查询失败重试的浏览器故障注入、真实远程订阅源和移动端视口本轮未单独执行；后端接口测试覆盖权限、订阅源与组合处理链。临时服务在验收后停止，不修改真实用户数据。
