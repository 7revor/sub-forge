# 全部名称筛选验收

日期：2026-10-29。

- 名称筛选采用字面包含匹配、忽略大小写与全半角；保留内部空格和标点。公开索引通过 SQL LIKE 查询，加密文档不新增明文名称列，按权限解密后使用等价谓词。
- 目录级联在后端完整目录中筛选后由前端保留嵌套路径；没有依赖分页加载更多才能查全的问题。
- 节点选择支持后端 q，先在完整处理结果筛选，再执行 5000 条上限；精确 NodeRef 匹配和正则含义保持原样。
- 异步选择器更换关键词立即失效旧请求、移除旧页并阻止提交旧候选；分页列表的旧结果仅在同关键词翻页时保留。
