## 提示取舍

| 类别 | 处理 | 理由 |
| --- | --- | --- |
| 规则集逐行不支持、解析失败、去重、改写移除、适配降级 | 从主配置报告移除 | 规则转换模块已经处理；转换统计、处理详情及输出注释保留。截图中的 `rule.client` 属于此类，不是重复发生的主配置故障。 |
| 缺少规则集、缺少快照、远程错误正文、托管格式不可用、直接远程规则转换后无有效输出 | 保留错误 | 规则转换无法自动修复资源不可用的问题，仍必须阻止错误订阅发布。 |
| 直接手写或结构化规则被丢弃、适配提示 | 保留 | 这些规则不必经过规则集模块，隐藏后可能遗漏实际分流变化。 |
| Loon 跨类型匹配优先级、客户端版本要求 | 保留 | 转换并不保证客户端执行语义或版本能力一致。 |
| 空策略组、引用回退或失效、代理链冲突或成环、名称冲突、源拉取失败 | 保留 | 会改变连接行为或阻止有效配置生成。 |
| 节点自动内联、代理链已写入 Provider | 本次未改动 | 属于说明性信息，价值低于错误和告警，不应解释成故障；它们不属于规则集逐行重复诊断。 |
