# YAML 输入高亮验收

日期：2026-10-29。分支：`codex/yaml-highlighting`，基于 `3a27168`。

## 实现范围

- 新增 `YamlTextarea`，保留原生 textarea 与事件，通过只读装饰层显示高亮；装饰层不进入无障碍树。
- 使用现有 `yaml` 的 [CST 解析接口](https://eemeli.org/yaml/#parsing-yaml) 区分语法，支持不完整文档，不解析别名、不改写输入、不渲染用户 HTML。
- 接入节点 / 模板 / 预设 / 配置订阅的双向编辑、分组 YAML 弹窗、模板导入、原样片段、YAML 格式本地规则及其他字段值。
- 未新增依赖，未安装或调用独立浏览器测试工具。
