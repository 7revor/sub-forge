# 基础设置页重新设计

日期：2026-10-30。基于 main@988aebe，独立工作树 `codex/base-settings-redesign`。

## 设计

原页面将订阅信息、输出设置、启用状态和两份原文拆为纵向多块；默认桌面视口看不到编辑框。新版将低频信息收紧，集中展示当前编辑目标。

- 沿用产品配色：文字 #15181d、次要文字 #5b6270、分隔线 #e3e6eb、页面底色 #f5f6f8、编辑面板 #ffffff、选中状态 #2952cc。
- 沿用现有中文无衬线字体；原文使用等宽字体。所有标签与内容左对齐。
- 顶部集中名称、流量 / 到期信息和备注；备注仍支持多行。
- 配置追加使用一个面板，启用开关并入标题栏。内核横向切换，公共层及客户端层采用侧边导航，每次只编辑一份原文。
- 桌面两栏，手机上下排列；用蓝点标记已有文本。说明、迁移记录默认折叠，减少常驻文字与重复卡片。

```text
订阅名称          流量 / 到期信息          备注
配置追加                                  启用开关
Mihomo        Surge        Stash        Loon
内核公共追加       当前层级标题        YAML / INI
客户端追加         作用范围
  FlClash          原文编辑框
  Clash Verge      保存说明              追加规则
配置迁移记录（折叠）
```

保持原有两层原文数据结构与保存逻辑，没有增加配置解析或跨内核转换。视图选择不写入订阅数据，暂停只隐藏编辑区并保留编辑位置。
