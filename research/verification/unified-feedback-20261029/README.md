# 全局操作反馈统一验收

日期：2026-10-29。
基线：`b6e0137`，分支：`codex/unified-feedback`。

## 变更范围

- 成功结果统一使用右上角悬浮通知，普通通知约 4.5 秒后关闭，悬停或键盘聚焦时暂停。
- 格式化、粘贴节点的通知保留撤销入口，手动关闭或后续编辑、禁用、离开编辑器时失效，防止覆盖后续草稿。
- 失败使用原生模态 `dialog`，语义为 `alertdialog`，正文按文本渲染。错误排队显示；同一错误在 mutation 回调与页面观察之间去重。
- Esc 只关闭最上层错误弹窗，保留背后的编辑表单与输入内容；关闭后恢复可用焦点。
- 已迁移登录、退出、复制、格式化、导入和视图恢复、保存与删除、账户密码、用户与共享、订阅链接、仓库管理与 Token、模板发布和切换、系统操作、订阅拉取、节点测试以及异步选项加载等操作反馈。
- 订阅拉取按每个返回项目的业务结果判断成功，HTTP 200 中的失败不会被通知为拉取成功；索引更新只通知“已提交”，不宣称索引已经完成。
- 原 `ErrorBox` 拆为不占文档流的 `ErrorAlert` 与随输入变化的 `FieldError`。字段校验、配置报告、历史快照、持久状态徽标和未保存提示仍保留，它们属于编辑内容或数据状态。

## 内置浏览器验收

使用 Codex 内置浏览器，前端端口 15189，临时后端端口 18089。后端采用项目测试工厂与内存数据库，只有虚构账户、节点和订阅地址；上游拉取使用测试工厂的失败响应，未连接真实订阅或生产数据库。

| 场景 | 结果 |
| --- | --- |
| 登录密码错误 | 显示统一失败弹窗；Esc 可关闭；再次失败仍显示 |
| 登录成功并跳转 | 新页面仍能看到成功通知，随后自动消失 |
| 创建本地分组并跳转 | 已保存通知显示于页面外层 |
| 节点格式化 | 通知在右上角，编辑器下方没有原操作提示行 |
| 格式化后撤销 | `name:` 后的四个空格格式化为一个，再撤销恢复四个空格 |
| 格式化后继续编辑 | 旧撤销通知消失，不留下覆盖新内容的入口 |
| 复制节点 YAML | 仅显示全局“已复制”，按钮保持“复制” |
| 粘贴无效 vmess 链接 | 失败弹窗显示导入原因，关闭后原节点和注释均保留，焦点返回编辑器 |
| 订阅源创建成功、自动拉取失败 | 弹窗显示测试上游失败原因，没有“订阅源已拉取”的成功通知 |
| 弹窗表单中提交无效订阅地址 | 统一错误弹窗覆盖表单，未产生双重错误弹窗 |
| 嵌套错误弹窗按 Esc | 仅关闭错误层，原新建表单及输入保留，焦点回到表单 |
| 表单再次提交同样无效地址 | 再次显示失败，不被旧错误去重逻辑吞掉 |

节点保存验收过程中遇到一次临时测试会话失效，统一错误弹窗正确显示“未登录”并跳转登录页；该次节点保存未记为通过。重新登录后继续完成订阅源相关验收。

未逐个点击验证密码更新、Token、发布模板、真实节点探测和远程仓库索引；这些路径完成代码迁移与类型检查。没有使用其他浏览器或安装 Playwright。
