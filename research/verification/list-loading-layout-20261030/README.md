# 列表加载布局稳定性验收（2026-10-30）

## 范围与约束

分支 `codex/list-loading-layout`，基于 `3cdfc45`，工作树 `.Codex/worktrees/list-loading-layout`。本次仅优化列表展示，不合并、不推送。

- 订阅源、组合、本地节点、增强集合、配置订阅、基础设置预设和模板：表头在加载、空结果、失败时常驻；正文使用 53px 骨架行，分页未知时显示破折号。
- 表格固定列宽，首列分配剩余空间；状态、模式标签截断并保留悬停说明；宽表在内容区内横向滚动。
- 通用列表搜索栏预留原有加载文案的空间，避免窄屏换行；滚动区预留滚动条宽度。
- 规则集合：仓库区域固定可视高度，仓库与规则文件各自保持表头、列宽及加载骨架，避免仓库返回后推移文件列表。
- 用户管理及详情页内表格不在本次修改范围。

## 前端缓存核对

`main.tsx`、`api.ts`、`hooks.ts`、所有查询 hooks、`session.ts` 和 `layout.tsx` 均无改动。

- 仍使用 `staleTime: 0`、`gcTime: 0`、挂载/聚焦/联网重读和现有 SSE 失效通知。
- 管理接口请求仍为 `cache: 'no-store'`，服务端 API 响应仍为 `Cache-Control: no-store`。
- 未新增内存缓存层、持久化缓存、前端数据保鲜时间或后台刷新时保留内容的处理。
- 原有当前查询结果、翻页及部分预览的 `placeholderData`、草稿状态保持原样；它们仍属于现有内存展示状态。
- 未发现前端业务数据写入 localStorage、sessionStorage、IndexedDB、Cache Storage 或 Service Worker；带哈希的 JS/CSS 静态资源浏览器缓存保持原样。

## 验证方式

复用已有依赖，未安装或调用独立浏览器、Playwright 或 Chromium。所有网页操作、截图、DOM 尺寸读取均使用 Codex 内置浏览器。

使用 `packages/server/test/manual-list-layout-server.ts`：内存数据库、虚构管理员和 24 个订阅源、模拟上游及仓库，不读取真实数据、不访问外部上游。通过 `LIST_LAYOUT_CONTROL` 指向的 JSON 控制列表响应、单元格响应和失败场景。使用独立域名 `http://list-layout.localhost:18947` 隔离同机其他开发实例的会话 Cookie。

前端使用本工作树生产构建。默认视口为 1280×720，窄屏为 390×844；窄屏检查后恢复默认视口。
