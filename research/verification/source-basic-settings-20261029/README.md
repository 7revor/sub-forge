## 实现范围

- 订阅源类型、保存、预览、拉取、种子统一使用 `url: string`；一个源只允许一个 HTTP(S) URL。旧版单元素 `urls` 请求和种子兼容转换，读取只返回 `url`；多元素、空数组、双字段、非法类型和多行地址拒绝。
- 数据库 v8 在事务内转换旧单地址文档，保留归属、更新时间、引用和快照；意外多地址导致事务回滚，不截断地址。
- 详情顶部为基础设置，单 URL 独占首行，名称与三个拉取选项使用统一 Field / Input 对齐，数值仍用 DraftInput；未引入新的 Form 依赖。其下方处理链与总览宽屏左右排列。
- PRD、领域模型、服务端与前端说明同步；设计稿调整写入 [待同步文档](../../../docs/13-design-canvas-sync.md)，未修改外部画布。
