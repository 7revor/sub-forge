# 列表操作与仓库表格验收

日期：2026-10-30。

## 改动

- 配置订阅、订阅源、本地节点、组合、增强集合、仓库、模板、用户列表复用 `ListActions`：操作右对齐，按钮高 32px，水平内边距 10px，按钮间距 8px。
- 删除入口使用红色描边和文字，位于编辑右侧；仓库删除从行内确认迁移到统一 `Frame.modal.confirm`，由运行时管理异步提交、防重、错误与关闭。系统公共资源删除入口同样改为红色。
- 模板列表按“新建订阅、编辑”排列，编辑文案与实际进入的管理员编辑页面一致。未新增服务端没有提供的模板删除功能。
- 仓库移除外层 Card，仅保留通用 `list-panel` 和 `ListTable`；无分页，按内容高度展示，超出上限时局部滚动。其他分页列表保留原有分页。
- 内存验收服务新增删除失败、延迟和请求计数控制，用于检查确认前无请求、失败重试、防重与晚到响应。

## 内置浏览器验收

使用 Codex 内置浏览器、`manual-list-layout-server.ts` 的虚构数据与内存数据库。未访问真实上游或修改用户数据。

1. 逐页检查配置订阅、本地节点、组合、增强集合、模板、用户列表；按钮高度均为 32px、水平内边距 10px、间距 8px。可删除列表均为最右侧红色删除，并出现带对象名称与影响说明的统一确认弹窗。订阅源另有完整截图。
2. 仓库仅有一层表格边框，无分页。1280×720 下三行表格及滚动容器均高 205px，无横向或纵向溢出；删除按钮完整可见。760×900 下页面宽度与滚动宽度同为 760px，仅仓库表格内部横向滚动。
3. 仓库删除的取消、右上关闭、Escape、遮罩均不发送 DELETE；重开仍展示最新对象名称。模拟首次删除失败，原弹窗保留且仅显示一份错误，不额外打开错误弹窗。
4. 同一弹窗重试时阻塞响应：确认与取消按钮禁用，Escape、遮罩和关闭按钮均不能结束正在提交的会话；请求计数仅从首次失败的 1 次增长为重试的 2 次。放行后仓库与对应文件索引移除。
5. 普通打开和提交中的路由离开均结束旧会话；延迟仓库删除请求在离开后完成，不改变新打开的本地节点删除弹窗的标题、正文和按钮状态。
6. `test/dialog-exit.html` 在 StrictMode 下逐帧记录 9 次动画退场，每次约 120 帧，全部通过：标题、正文、输入值及布局高度保持一致。覆盖取消、关闭、Escape、遮罩、不同名称重开、失败重试、嵌套子弹窗、父弹窗、路由离开；另验证无动画下取消正常结算。详见 `lifecycle-results.txt`。
7. 系统页已访问；该虚构数据没有公共规则资源，未执行非空系统资源列表的删除交互。用户列表仅验证操作尺寸与间距，未修改用户权限或密码。
