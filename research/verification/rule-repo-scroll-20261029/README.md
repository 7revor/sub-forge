# 规则仓库左右独立滚动 · 2026-10-29

基于 `main@667d50d`，在 `codex/rule-repo-index` worktree 修改。纯前端布局变更，服务端接口、领域模型与种子不变。

## 实现

- 移除包住左右两栏的共同滚动层，宽屏网格占据页面剩余高度。
- 左侧数量与分页固定，规则列表单独滚动；右侧详情独立滚动，并阻止滚动传递到外层。
- 翻页重置列表位置，切换规则重置详情位置。
- 1024 px 以下上下排列，分别保留 240/320 px 最小高度；内容区允许上下滚动，避免列表被顶部筛选挤压。

## 验收

使用 Codex 内置浏览器与其 CDP 开发接口，连接回环端口 18184 的隔离测试实例；未使用独立 Playwright 或其他浏览器。

- 1440×900：左侧列表可视高度 535 px、内容 3262 px；详情可视高度 636 px、内容 1022 px。
- 滚轮作用于左侧：`left.scrollTop = 500`、`right.scrollTop = 0`。
- 再滚右侧：`left.scrollTop = 500`、`right.scrollTop = 300`，文档滚动为 0，页头 top 始终为 28 px。见 [独立滚动](independent-scroll.jpg)。
- 左侧翻到第 2 页，列表回到顶部（scrollTop 0），首条变为 zydou 的 abc，分页操作始终可见。
- 390×844：文档宽度 390 px，无页面横向溢出；列表可视高度 137 px、详情高度 318 px，外层内容区可滚动访问上下两区。见 [窄屏](narrow.jpg)。
- `pnpm --filter @sub-forge/web build` 通过（含 TypeScript 检查）。仅存在原有 bundle 大小提示；此次纯布局修复以浏览器交互验证为准。

外部设计画布仍待同步，已记录在 docs/11 与 docs/13。浏览器临时视口在结束时恢复，测试服务在验收后停止。
