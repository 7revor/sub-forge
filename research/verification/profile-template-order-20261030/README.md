# 订阅模板整体排序与预览标签验收

日期：2026-10-30。工作分支：`codex/profile-template-order`。

## 行为

- 自定义规则并入「规则」列表；自定义规则、策略组仅使用绿色背景区分。
- 模板规则、策略组各自作为一个锁定的排序区块；自定义项可拖动排序，只能位于模板整体两端。
- 前后规则分别保存到 `prependRules`、`appendRules`；后置规则位于模板规则之后、最终 MATCH 之前。
- 自定义组仍保存在 `extraGroups`；`prependGroupIds` 标记模板前侧的组。未携带新字段的已有文档保留原有顺序。
- 关联模板时开放新增策略组及地区节点按钮，继续使用统一弹窗和会话草稿；取消新增不会加入页面列表。
- 第三个标签为「预览」，点击时渲染当前草稿；支持左右键与 Home、End 切换。

## 内置浏览器验收

使用 `@Browser`，本地内存数据库及虚构节点；服务来自项目已有的 `manual-prepend-rules-server.ts`，仅绑定回环地址。未安装或调用独立浏览器测试运行时。

1. 关联模板的新增组入口可用；取消新增后仍为原来的两个模板组，重开获得干净草稿。
2. 新增「自定义出口」并添加 DIRECT，保存弹窗后出现在绿色自定义卡片中；移至最上方后模板两组保持内部顺序。
3. 添加本地规则直接进入主规则列表；通过空格、上箭头、空格的键盘拖动跨越整个模板区块。
4. 再添加一条后置规则；保存订阅、刷新页面后，前置项、模板整体、后置项的位置保持。
5. 预览输出为前置 DOMAIN、模板 DOMAIN-SUFFIX、后置 DOMAIN、MATCH；策略组输出自定义组在前。报告为 0 错误、0 告警。
6. 三个标签顺序正确；End 跳到预览，左箭头回核心设置。
7. 已保存策略组重开显示原成员；修改名称后 Escape 取消，页面仍为原名称、已保存状态。取消、确认及关闭按钮退场时，标题、输入值和成员仍保留到卸载。
8. 最终构建后再次刷新，核对保存状态与两侧规则并更新截图。

本次复用原有弹窗，未修改弹窗运行时或表单内部。浏览器未额外注入异步提交失败、StrictMode、无动画、路由卸载或嵌套场景；这些不宣称为本次浏览器通过项，生命周期自动测试仍通过。
