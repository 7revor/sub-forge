# @sub-forge/web

管理前端：React 19 + React Router 7 + TanStack Query + Tailwind 4，配色与布局取自设计稿（Claude Design 画布「Sub-Forge 前端页面设计」）。

## 开发

本地推荐使用仓库中的 [一键开发脚本](../../scripts/README.md)，同时启动 Vite 热更新与后端源码监听，不需要打包。以下是分别启动两个服务的方式：

```bash
# 终端 1：后端（示例数据见 packages/server/README.md）
SUBFORGE_DB=./data/dev.db PORT=8787 PUBLIC_URL=http://127.0.0.1:5173 pnpm --filter @sub-forge/server start
# 终端 2：前端，/api /sub /p /r 代理到后端
SUBFORGE_API=http://127.0.0.1:8787 pnpm --filter @sub-forge/web dev
```

生产构建由服务端托管（`WEB_DIR=packages/web/dist`），生产镜像已包含，前端与接口同源。

## 页面

页面结构以设计稿为准：原有 21 张画板 + 补充的 8 张 + 本地节点编辑子页 1 张（处理链步骤编辑、处理器表单、基础设置（画布待同步）、列表页、对话框、模板浏览、登录、账户）。逐页对照见 [docs/11](../../docs/11-design-coverage.md)。

处理链的「添加旗帜」参数提示说明：地区名或代码可识别，流量与到期等说明节点不加旗帜，已有旗帜不重复添加。

| 路由 | 页面 |
| --- | --- |
| `/` | 总览：四项统计（配置订阅、订阅源、孤儿覆盖项、近 24 小时请求与缓存命中）、配置订阅最近访问与状态、待处理事项、订阅源流量与到期 |
| `/sources`、`/sources/:id` | 订阅源列表（搜索、备注、节点数、上次拉取、状态，空备注留白，不显示处理链列，新建为对话框）；详情上方为「基础设置」，下方「处理链｜总览」左右排列，窄屏自然换行。表单参考规则集来源设置，复用 Field / Input：单个订阅地址独占一行，名称、User-Agent、快照有效期和超时等列对齐，不引入第三方 Form 库；快照历史可展开。修改地址或拉取选项后自动预览草稿；「保存修改」统一提交，未保存时「保存并拉取」先保存再拉取 |
| `/collections`、`/collections/:id` | 组合：成员表（类型、节点数、前后缀、拉取失败时），下方当页展开处理链编辑器与逐步预览（预览跟随成员草稿），头部显示引用方；旧地址 `/collections/:id/pipeline` 跳回详情页 |
| `/locals`、`/locals/:id`、`/locals/:id/nodes/:index` | 本地节点：分组列表（与订阅源一致：搜索、节点数、协议，新建分组为对话框）；分组详情在「基本信息」中直接编辑名称与备注，通过页头统一保存，下方为节点表；分组 YAML 使用对话框；「编辑」「新增节点」进入节点子页（`index` 为 `new` 时新增），表单 / YAML 编辑（不设置前置，代理链在配置订阅中设置），保存即写回分组，删除节点使用独立按钮。有未保存修改时离开前确认 |
| `/profiles`、`/profiles/new`、`/profiles/:id/:tab` | 配置订阅：七步向导；详情头部显示模板（点开可更换 / 锁定版本）、预设与最近告警。概览（订阅链接与最近访问、输出设置、访问日志）、基础设置（来源条、进程规则提醒、按分区覆盖 / 来自预设、原样片段）、节点集（添加对话框、输出方式与下发地址）、策略组、规则（客户端输出列）、代理链（唯一的代理链入口：只读卡片 + 编辑对话框、依赖节点）、预览（打开即渲染、导出文件） |
| `/rulesets`、`/rulesets/:id` | 规则集：列表（来源概况、no-resolve）；新建（`/rulesets/new`）与编辑共用同一页面。自上而下为来源（多个远程地址 / 本地规则，拖拽排序、启停，点选展开地址、格式、缓存等字段，本地规则输入框紧跟对应配置）、独立的客户端改写区块（先选替换、丢弃或追加；替换和丢弃再填写规则内容精确匹配；追加按客户端与平台条件直接加入规则，无需匹配）、输出预览（选中来源时只读展示该来源，取消选中或点击「查看合并结果」恢复整组合并输出；切换时不沿用上一来源内容），每块独占一行；预览跟随未保存的草稿。原规则包页面 `/bundles` 已并入规则集（2026-10-29） |
| `/rule-repo` | 规则仓库：搜索、仓库筛选、按客户端的变体与内容预览、引用为规则集或作为远程来源加入已有规则集（`?ruleset=` 进入，内置仓库已接通） |
| `/templates`、`/templates/:id`、`/templates/:id/publish` | 仅管理员显示唯一「模板」入口，可新建、编辑与发布（骨架表格、规则、版本、自检、从 YAML 导入）；旧 `/templates/manage` 跳转到 `/templates`。普通用户在配置订阅向导中选择已发布模板 |
| `/presets`、`/presets/:id` | 基础设置预设：列表支持搜索、新建、删除和编辑；独立详情页按通用、外部控制、DNS、嗅探、TUN、GEO 数据折叠分组（默认收起，可独立展开），支持表单 / YAML 编辑、发布与引用方，未发布修改离开前确认 |
| `/users`、`/system` | 管理员：用户（统计列、脚本权限、共享的订阅源与组合）；系统（SSRF 白名单、mihomo 校验、内置及自定义规则仓库已接通，其余系统设置、备份恢复仍待实现） |
| `/login`、`/account` | 登录、账户（修改密码） |

删除是独立按钮：详情页在头部操作区最右侧（保存之后），列表每行在「编辑」左侧；点击后弹确认对话框，被引用时对话框里列出引用方。所有顶部操作（包括重命名、复制等）按顺序直接显示为按钮，不使用「更多」折叠菜单；空间不足时自动换行。对话框的结构与宽度见 `components/ui.tsx` 的 `Modal`。

本地节点通过「新增节点 / 编辑 → 原始配置」直接粘贴单节点分享链接、YAML、JSON、Base64 或 Surge 节点。完整节点自动替换编辑草稿、格式化为 Mihomo YAML 并同步表单，保存后生效；普通字段片段按光标位置插入。多个节点、损坏或不支持的配置显示原因并保留原草稿，不导入部分结果。2026-10-29 移除分组列表独立的「粘贴导入」入口。普通网页 / 订阅 URL 请放入订阅源，本地粘贴不联网拉取。

## 服务端尚未实现的功能

界面已按设计稿就位，服务端暂时只有占位接口（`packages/server/src/api/pending.ts`）：读接口返回空数据并带 `pending: true`，页面据此显示「服务端尚未实现」提示；写接口返回 501，错误会在页面上显示。涉及：镜像及其余系统设置、用户统计列、共享。内置仓库索引、搜索、预览与文本导入已接通。另有几个字段随文档保存但渲染尚未读取：组合成员的「拉取失败时」、配置订阅基础设置的原样片段。

## 编辑方式

表单为主、原始配置为辅（[docs/09](../../docs/09-frontend-forms-plan.md)）：模板、本地节点、基础设置与预设都可以在「表单」与「原始配置（mihomo YAML）」之间切换，两者编辑同一份数据；有效的未知扩展字段在「其他字段」中按键值编辑。

YAML 输入统一使用 `YamlTextarea`：浅色背景、等宽字体、键名 / 字符串 / 数字 / 布尔与空值 / 注释 / 锚点与标签高亮。覆盖双向编辑器、分组 YAML、模板导入、基础设置原样片段、明确选择 YAML 格式的本地规则，以及其他字段的 YAML 值。高亮复用已有 `yaml` 的 CST 解析器，不改写输入；保留原生选择、撤销、粘贴、标签关联与校验反馈，长行横向滚动、多行纵向滚动、可调整高度。非 YAML 的备注、规则和脚本输入继续使用普通文本框。

所有双向编辑器均允许缺项、字段类型错误或 YAML 语法错误时返回表单：只保留能可靠解析的有效字段，清空无效字段，逐项提示被忽略的内容。重复键保留第一项；列表保留有效条目；未知扩展字段保留；无法确定含义的损坏片段不猜测修复。再次切回原始视图时显示清理后的 YAML。原始视图尚有解析错误时仍禁止保存；返回表单后可继续补齐，保存 / 发布仍执行必填项与业务校验。批量节点导入保持严格校验。

Profile 基础设置的无效 YAML 同时阻止分区 / 侧栏导航与向导步骤跳转；返回表单恢复有效字段后解除拦截，也可直接修复原文或明确放弃。节点与预设不会把无效原文显示为“已保存”。模板 YAML 导出使用 `sub-forge-group` / `sub-forge-rule` 注释保留稳定 ID，因此改名或改匹配内容仍能关联已有个人覆盖。返回表单时无效组字段被清理、坏规则被忽略；无效组类型使用默认 select；原 final 引用的组不存在时改为 REJECT 并提示。复制组或规则时建议删除复制项的 ID 注释；恢复解析会忽略重复注释并保证 ID 唯一。

全局 blank 使用 `Empty.tsx` 的公共 `Empty`（由 `ui.tsx` 导出），包括列表、详情、预览、功能占位和下拉无结果。说明与空框间距由 `Card description` 或 `gap-4` 保证 16 px，不依赖默认段落 margin。尺寸、适用范围与设计稿待同步项见 [空状态规范](../../docs/14-empty-state-guidelines.md)。

公共组件在 `src/components/`：`listbox`（`Select` 单选下拉与 `Combobox` 可输入下拉，所有下拉都用它们，不使用浏览器原生 `<select>` / `<datalist>`，弹层渲染到 body、层级高于对话框）、`DetailActions`（平铺操作按钮 `ActionButtons`、删除按钮 `DeleteAction` 与删除确认 `DeleteDialog`）、`dialogs`（重命名、添加节点集）、`DualEditor`（双视图）、`SchemaForm`（字段描述驱动的表单，字段定义在 `src/schemas/`）、`OverrideField`（逐项覆盖）、`SortableList`（拖拽排序，支持锁定项）、`RuleEditor`、`ClientOverrides`、`NodePicker`、`MatchPreview`。格式转换在 `src/convert/`，都有单元测试。

公共展示与业务表单的复用边界：

- `CopyButton` / `useClipboard`：等待剪贴板写入成功再反馈，失败显示原因；文本变化与卸载使旧反馈失效。
- `CodePreview`、`Notice`、`NodeSetCount`、`SourceFetchStatus`、`Card subtitle`：统一预览、提示、节点计数、拉取状态与卡片标题说明。`ReportList` 可由调用方提供定位操作；模板版本列表复用 `template/VersionHistory`。
- `GroupSettingsFields`、`MatcherEditor`、`OptionalBoolean`：模板与配置订阅共用字段；权限、继承和覆盖写入仍由页面负责。布尔值区分未设置、开启和关闭，数值 `0` 保留。规则匹配类型切换清理旧类型专属字段。
- `NamedCreateDialog`：本地分组与预设共用名称校验、回车提交、重复提交保护和错误展示。`ExtraFields.validateName` 同时用于新增和重命名，调用方通过业务校验函数限制字段，不依赖 DOM 事件捕获。
- `useLeaveGuard` / `LeaveDialog`：本地节点及预设有未保存修改或无效 YAML 时保护路由跳转与刷新；合法内容可以保存后离开，无效内容需继续编辑或明确放弃。Profile 保持仅无效 YAML 阻断的原策略。
- `hooks/documentQueries` 集中定义 token、访问日志和快照查询；`usePipelinePreview` 供订阅源与组合使用；`useDebouncedValue` 复用普通值防抖。节点集标识、匹配项切换、拉取状态及删除错误归入 `domain/`，时间与流量格式化归入 `utils/format.ts`。

## 已知简化

- 外部 YAML 没有稳定 ID 注释时，模板导入仍按组名 / 规则匹配项识别；同时删除注释并改名无法可靠识别原组，可能需要重新关联个人覆盖。
- Surge 基础设置、预设的 Surge 段与 Surge 预览在 M2，界面里的 Surge 切换先显示占位说明。
- 订阅源要先创建才能编辑处理链（预览接口需要订阅源 ID，支持未保存的基础设置与处理链草稿），所以新建是对话框，创建后直接进入编辑器。
- 节点集「下发地址」显示为路径模式，实际地址带 token 与内容版本，以预览中的配置为准。

来源的「不支持 N 行」徽标支持悬停、键盘聚焦和点击查看详情：列出行号、原文、原因，点击固定浮层；Escape、关闭按钮或点击外部关闭。最多显示前 100 条，保留完整计数。


2026-10-29：规则仓库已接入真实内置索引、名称搜索、仓库/客户端筛选、分页、内容预览与文本变体导入。规则仓库页及系统页显示索引状态，管理员可更新/启停；镜像仍为占位。详情未读取前不展示虚构条数，预览失败可重试；导入完成刷新规则集查询缓存。

2026-10-29：系统页新增公开 GitHub 仓库表单（URL、名称、分支、目录、包含/排除 glob、格式），新增后异步显示索引进度，支持启停、更新和删除确认。规则仓库页展示自定义名称与完整文件路径、通用文本变体、解析错误及不支持行的 hover/点击弹层；无有效规则时禁用自定义导入。一个文件一个条目，核心解析和规则集合并流程复用现有能力。



规则仓库的结果列表与详情在宽屏独立滚动；结果数量、分页和顶部筛选固定。切换分页或规则后，对应区域回到顶部。窄屏上下排列并保留最小可用高度。仅涉及布局，沿用已有索引、搜索、预览和导入接口。

规则集来源区支持公共 `AsyncSelect` 懒加载关联：打开请求、30 条分页、300ms 搜索防抖、错误重试及键盘选择；旧响应被隔离，候选文本不能直接作为值提交。关联来源使用 Link2 图标与只读 URL，自定义远程用 Globe 和可编辑 URL；解析结果只进入草稿，页头保存生效。

规则仓库仅展示 list/txt，自定义仓库格式配置不含 YAML。规则集「输入格式」仍支持自动检测远程 YAML payload 并转换为托管 LIST，转换完成显示徽标；已知 YAML 输入不提供 mrs 透传选项，原 URL 保留用于更新。

### GitHub 索引 Token

系统的规则仓库卡片支持管理员配置、替换和清除 Token；密码输入保存后清空，读取仅显示配置状态。保存后点击仓库「更新索引」验证，无需重启。Token 独立保存，不依赖仍占位的系统设置总保存按钮。

### 规则仓库首页

上方集中仓库添加、删除自定义仓库、启停、刷新与 Token；下方搜索结果和详情分别滚动。右侧按分支与文件路径列出文本文件，每行「新建规则集」只关联一个文件，不再选择客户端或推荐组合。系统页保留认证与仓库首页链接。
