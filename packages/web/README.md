# @sub-forge/web

管理前端：React 19 + React Router 7 + TanStack Query + Tailwind 4，配色与布局取自设计稿（Claude Design 画布「Sub-Forge 前端页面设计」）。

## 开发

本地推荐使用仓库中的 [一键开发脚本](../../scripts/README.md)，同时启动 Vite 热更新与后端源码监听，不需要打包。以下是分别启动两个服务的方式：

```bash
# 终端 1：后端（示例数据见 packages/server/README.md）
SUBFORGE_DB=./data/dev.db PORT=8787 PUBLIC_URL=http://127.0.0.1:5173 pnpm --filter @sub-forge/server start
# 终端 2：前端，/api /sub /p /r 代理到后端
SUBFORGE_API=http://127.0.0.1:8787 pnpm --filter @sub-forge/web dev
```

生产构建由服务端托管（`WEB_DIR=packages/web/dist`），生产镜像已包含，前端与接口同源。

## 页面

页面结构以设计稿为准：原有 21 张画板 + 补充的 8 张 + 本地节点编辑子页 1 张（处理链步骤编辑、处理器表单、拉取参数、列表页、对话框、模板浏览、登录、账户）。逐页对照见 [docs/11](../../docs/11-design-coverage.md)。

处理链的「添加旗帜」参数提示说明：地区名或代码可识别，流量与到期等说明节点不加旗帜，已有旗帜不重复添加。

| 路由 | 页面 |
| --- | --- |
| `/` | 总览：四项统计（配置订阅、订阅源、孤儿覆盖项、近 24 小时请求与缓存命中）、配置订阅最近访问与状态、待处理事项、订阅源流量与到期 |
| `/sources`、`/sources/:id` | 订阅源列表（搜索、节点数、上次拉取、状态，新建为对话框）；详情从上到下依次为拉取参数、处理链步骤、编辑与实时预览。名称、多个地址、User-Agent、快照有效期和超时在页内编辑，快照历史可展开。修改拉取参数后自动预览草稿；「保存修改」统一提交，未保存时「保存并拉取」先保存再拉取 |
| `/collections`、`/collections/:id` | 组合：成员表（类型、节点数、前后缀、拉取失败时），下方当页展开处理链编辑器与逐步预览（预览跟随成员草稿），头部显示引用方；旧地址 `/collections/:id/pipeline` 跳回详情页 |
| `/locals`、`/locals/:id`、`/locals/:id/nodes/:index` | 本地节点：分组列表（与订阅源一致：搜索、节点数、协议，新建分组为对话框）；分组详情为节点表，粘贴导入、分组 YAML、重命名为对话框；「编辑」「新增节点」进入节点子页（`index` 为 `new` 时新增），表单 / YAML 编辑（不设置前置，代理链在配置订阅中设置），保存即写回分组，删除节点使用独立按钮。有未保存修改时离开前确认 |
| `/profiles`、`/profiles/new`、`/profiles/:id/:tab` | 配置订阅：七步向导；详情头部显示模板（点开可更换 / 锁定版本）、预设与最近告警。概览（订阅链接与最近访问、输出设置、访问日志）、基础设置（来源条、进程规则提醒、按分区覆盖 / 来自预设、原样片段）、节点集（添加对话框、输出方式与下发地址）、策略组、规则（客户端输出列）、代理链（唯一的代理链入口：只读卡片 + 编辑对话框、依赖节点）、预览（打开即渲染、导出文件） |
| `/rulesets`、`/rulesets/:id` | 规则集：列表（来源概况、no-resolve）；新建（`/rulesets/new`）与编辑共用同一页面。自上而下为来源（多个远程地址 / 本地规则，拖拽排序、启停，点选展开地址、格式、缓存等字段）、独立的客户端改写区块（作用于整个规则集，只按规则内容精确匹配）、输出预览（选中来源时为该来源，本地规则在预览里实时编辑；不选时为合并结果），每块独占一行；预览跟随未保存的草稿。原规则包页面 `/bundles` 已并入规则集（2026-10-29） |
| `/rule-repo` | 规则仓库：搜索、仓库筛选、按客户端的变体与内容预览、引用为规则集或作为远程来源加入已有规则集（`?ruleset=` 进入，服务端待实现） |
| `/templates`、`/templates/:id`、`/templates/:id/publish` | 仅管理员显示唯一「模板」入口，可新建、编辑与发布（骨架表格、规则、版本、自检、从 YAML 导入）；旧 `/templates/manage` 跳转到 `/templates`。普通用户在配置订阅向导中选择已发布模板 |
| `/presets/:id` | 基础设置预设（单页）：预设列表、分区跳转编辑、引用方 |
| `/users`、`/system` | 管理员：用户（统计列、脚本权限、共享的订阅源与组合）；系统（SSRF 白名单、mihomo 校验、规则仓库、备份恢复，服务端待实现） |
| `/login`、`/account` | 登录、账户（修改密码） |

删除是独立按钮：详情页在头部操作区最右侧（保存之后），列表每行在「编辑」左侧；点击后弹确认对话框，被引用时对话框里列出引用方。所有顶部操作（包括重命名、复制等）按顺序直接显示为按钮，不使用「更多」折叠菜单；空间不足时自动换行。对话框的结构与宽度见 `components/ui.tsx` 的 `Modal`。

本地节点的「粘贴导入」支持单个 YAML 节点、以 `-` 开头的节点列表及带 `proxies` 的完整配置，无需手动包装单节点；整体缩进片段也可直接粘贴。YAML 语法错误在弹窗显示并禁止导入，列表中字段缺失的节点逐项报告，其余有效节点可继续导入；导入后需保存分组。

## 服务端尚未实现的功能

界面已按设计稿就位，服务端暂时只有占位接口（`packages/server/src/api/pending.ts`）：读接口返回空数据并带 `pending: true`，页面据此显示「服务端尚未实现」提示；写接口返回 501，错误会在页面上显示。涉及：规则仓库、系统设置、用户统计列、共享。另有几个字段随文档保存但渲染尚未读取：组合成员的「拉取失败时」、配置订阅基础设置的原样片段。

## 编辑方式

表单为主、原始配置为辅（[docs/09](../../docs/09-frontend-forms-plan.md)）：模板、本地节点、基础设置与预设都可以在「表单」与「原始配置（mihomo YAML）」之间切换，两者编辑同一份数据；有效的未知扩展字段在「其他字段」中按键值编辑。

所有双向编辑器均允许缺项、字段类型错误或 YAML 语法错误时返回表单：只保留能可靠解析的有效字段，清空无效字段，逐项提示被忽略的内容。重复键保留第一项；列表保留有效条目；未知扩展字段保留；无法确定含义的损坏片段不猜测修复。再次切回原始视图时显示清理后的 YAML。原始视图尚有解析错误时仍禁止保存；返回表单后可继续补齐，保存 / 发布仍执行必填项与业务校验。批量节点导入保持严格校验。

Profile 基础设置的无效 YAML 同时阻止分区 / 侧栏导航与向导步骤跳转；返回表单恢复有效字段后解除拦截，也可直接修复原文或明确放弃。节点与预设不会把无效原文显示为“已保存”。模板 YAML 导出使用 `sub-forge-group` / `sub-forge-rule` 注释保留稳定 ID，因此改名或改匹配内容仍能关联已有个人覆盖。返回表单时无效组字段被清理、坏规则被忽略；无效组类型使用默认 select；原 final 引用的组不存在时改为 REJECT 并提示。复制组或规则时建议删除复制项的 ID 注释；恢复解析会忽略重复注释并保证 ID 唯一。

公共组件在 `src/components/`：`listbox`（`Select` 单选下拉与 `Combobox` 可输入下拉，所有下拉都用它们，不使用浏览器原生 `<select>` / `<datalist>`，弹层渲染到 body、层级高于对话框）、`DetailActions`（平铺操作按钮 `ActionButtons`、删除按钮 `DeleteAction` 与删除确认 `DeleteDialog`）、`dialogs`（重命名、添加节点集）、`DualEditor`（双视图）、`SchemaForm`（字段描述驱动的表单，字段定义在 `src/schemas/`）、`OverrideField`（逐项覆盖）、`SortableList`（拖拽排序，支持锁定项）、`RuleEditor`、`ClientOverrides`、`NodePicker`、`MatchPreview`。格式转换在 `src/convert/`，都有单元测试。

## 已知简化

- 外部 YAML 没有稳定 ID 注释时，模板导入仍按组名 / 规则匹配项识别；同时删除注释并改名无法可靠识别原组，可能需要重新关联个人覆盖。
- Surge 基础设置、预设的 Surge 段与 Surge 预览在 M2，界面里的 Surge 切换先显示占位说明。
- 订阅源要先创建才能编辑处理链（预览接口需要订阅源 ID，支持未保存的拉取参数与处理链草稿），所以新建是对话框，创建后直接进入编辑器。
- 节点集「下发地址」显示为路径模式，实际地址带 token 与内容版本，以预览中的配置为准。
